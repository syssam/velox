# Per-package statement-coverage floors, checked by scripts/covfloor in CI and in
# scripts/ci-local.sh:
#
#   go run ./scripts/covfloor -floors scripts/coverage-floors.txt cover-root.out cover-example.out cover-veloxotel.out cover-graphql.out
#
# One "<import path> <percent>" per line. A floor is the coverage measured at its
# commit minus 1.0 (at least 0.0), so that a small change does not trip it but a
# real loss of tests does. The profiles are `go test -race -count=1 -coverprofile`,
# per module (root, example, contrib/veloxotel, contrib/graphql), merged by block.
# The floors were measured without any database variable set, so the DB-gated
# tests were skipped: CI runs them, which can only add coverage, so a floor that
# holds here holds there. Measured twice, with identical per-package figures.
#
# To raise a floor after adding tests, or lower one after a deliberate loss, put the
# measured value minus 1.0 here; the checker prints it. A new package needs a line.
#
# Packages at 0.0 have no tests of their own: generated code (*/gen, */schema,
# graphql/graph), the demo schemas and the committed golden helpers; they are
# exercised only by other packages' tests, which -coverprofile without -coverpkg
# does not count. internal/itest has no statements and no line.
