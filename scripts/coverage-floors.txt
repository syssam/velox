# Per-package statement-coverage floors, checked by scripts/covfloor on a push to
# main and in scripts/ci-local.sh --full:
#
#   go run ./scripts/covfloor -floors scripts/coverage-floors.txt cover-root.out cover-root-graphql.out cover-examples.out cover-examples-graphql.out cover-examples-otel.out cover-veloxotel.out cover-graphql.out
#
# One "<import path> <percent>" per line. A floor is the coverage measured at its
# commit minus 1.0 (at least 0.0), so that a small change does not trip it but a
# real loss of tests does. The profiles are `go test -race -count=1 -coverprofile`,
# per module (root, examples, contrib/veloxotel, contrib/graphql; the examples in
# three runs: its ORM examples, examples/graphql and examples/otel), merged by block.
# The root module's run adds -coverpkg=./..., as most of the root package's tests are
# in internal/apitest, internal/engine and internal/integration. The figures depend on the
# toolchain: go1.27.2 counts some blocks' statements differently from go1.27.1, which
# moved bench/scale's figure with no change to its code or tests.
# The floors were measured without any database variable set, so the DB-gated
# tests were skipped: CI runs them, which can only add coverage, so a floor that
# holds here holds there. Measured twice, with identical per-package figures.
#
# To raise a floor after adding tests, or lower one after a deliberate loss, put the
# measured value minus 1.0 here; the checker prints it. A new package needs a line.
#
# Packages at 0.0 have no tests of their own: generated code (*/gen, */schema,
# graphql/graph), the demo schemas, the committed golden helpers and
# cmd/velox-graphql, whose main is one call into internal/gqlplugin; they are
# outside the root module, exercised only by other packages' tests, which
# -coverprofile without -coverpkg does not count. internal/integration and internal/apitest
# have no statements and no line.
