# Decisions

Each record is a binding decision of velox's design, with its context, its
consequences and where it is enforced: a test, the code, or the spec line it
came from. The specs in [docs/history/specs](../history/specs/) and the plans in
[docs/history/plans](../history/plans/) hold every ruling; these are the ones a user or a
contributor needs to know.

| Record | Decision |
| --- | --- |
| [0001](0001-ent-names.md) | Tables, columns, indexes, constraints and inflection follow ent's, so an ent database baselines without renames. (amended by 0090) |
| [0002](0002-no-inflect-dependency.md) | Plural's rules are copied from go-openapi/inflect v0.19.0 into the stdlib-only plugin package, and the naming helpers' outputs never change within a major version. |
| [0003](0003-nullability.md) | Optional stays NOT NULL, as in veloxe; Nillable makes a column NULL-able. (amended by 0063; superseded in part by 0090) |
| [0004](0004-versioning.md) | Semantic versioning from 1.0, except generated code: its version constant is replaced in a minor release; schema.json and velox.json read older versions and refuse newer ones. |
| [0005](0005-deprecation.md) | Nothing is deprecated before 1.0; after 1.0, `// Deprecated:` until the next major version. |
| [0006](0006-own-migrate-and-atlas.md) | velox keeps its own planner and ships `migrate sql` for Atlas; a directory is managed by one of them. (amended by 0113, 0167) |
| [0007](0007-policies-decide-hooks-query.md) | Policies decide from the context and the row; a rule that must see other rows is a hook. (revised by 0039) |
| [0008](0008-write-policies-filter.md) | A Write policy filters: a write to rows it hides affects 0 rows, not an error. |
| [0009](0009-mutations-return-as-written.md) | A GraphQL mutation returns the row as written; a many-to-many link needs Read on the target, a link from the owner that sets its key Write. (amended by 0045) |
| [0010](0010-savepoint-per-mutation.md) | Superseded by 0045. Each GraphQL mutation runs in a savepoint of the operation's transaction. |
| [0011](0011-bidirectional-edges.md) | A self edge with no inverse is bidirectional, as in ent: links and unlinks write both directions. |
| [0012](0012-drift-never-hides.md) | Drift never hides a real difference, except a cast whose meaning depends on the column's type. |
| [0013](0013-version-floors.md) | migrate needs PostgreSQL 14, MySQL 8.4 or SQLite 3.35. |
| [0014](0014-with-stays-a-method.md) | Query.With and Rel.With stay methods: as functions they would save 1638 bytes, under 1%. |
| [0015](0015-contrib-graphql-path.md) | The module path stays contrib/graphql, imported as `vgraphql` beside gqlgen's graphql. |
| [0016](0016-withtenant-converts.md) | Superseded by 0029: `WithTenant` converted a predeclared integer or a string to the tenant column's type. |
| [0017](0017-upsert-skips-updatedefault.md) | An upsert's update branch does not fire UpdateDefault, as in veloxe and ent. |
| [0018](0018-pgx-stdlib-scan-wrapper.md) | On pgx's stdlib driver, scans go through a sql.Scanner, so pgx's per-column type check passes at its first step: 81% less time for a 100-row query with time columns (the before and after runs had different loads). |
| [0019](0019-veloxpgx.md) | pgx's native path is the package veloxpgx in this module; the core reads pgx's errors by type name, so it links no driver. |
| [0020](0020-root-and-engine.md) | The root package is the generic API and `internal/engine` is the rest: the root's `DB` holds an `engine.DB`, its public names are aliases, and each test lives by the code it tests. (amended by 0053) |
| [0021](0021-veloxtype.md) | The plain data types are in the public package `veloxtype`, which the root re-exports, so their fields and methods have real documentation; what reaches a private field stays in the engine. |
| [0022](0022-group-by.md) | Grouped aggregates take `handle.Key()`, a generic method, since an ordinary method or a phantom field costs every entity package (superseded by 0158: the bare handle); a group list obeys `AllowUnbounded()` and the row cap; NULL keys are nil, NULL sums 0, and an empty group has no average, least or greatest. (amended by 0067; superseded in part by 0158) |
| [0023](0023-module-path.md) | The module is `github.com/syssam/velox`; the earlier project is veloxe, and its tags are never reused |
| [0024](0024-public-surface.md) | The public API is pinned by a snapshot; `migrate.Change` is opaque; `internal/engine` exports only what crosses it |
| [0025](0025-connect.md) | `velox.Connect` opens a database in one call; `DB.Close` closes only what it opened; `velox.Pool` is the `*sql.DB` under it |
| [0026](0026-migration-safety.md) | `Up` refuses to destroy what the model cannot hold: a SQLite rebuild and a MySQL `MODIFY COLUMN` are checked against the database at apply time, and `-- velox:allow unmodeled-loss` accepts the loss. |
| [0027](0027-graphql-limits.md) | The cost charges statements and introspection's response; a Required edge is nullable; the generator refuses what could only fail later; an explicit zero value on a Default is refused in GraphQL and stays unset in the core (that rule superseded by 0082) (amended by 0108; superseded in part by 0029, 0045; the compat=veloxe parts superseded by 0156) |
| [0028](0028-runtime-edges.md) | The runtime's edges fail or say so: After needs its order columns selected, a nested Tx's error means its work is undone, SQLite enforces TxReadOnly and writes velox's time form, a statement inside Iter on a pool of one fails rather than hang, a MySQL deadlock breaks its transaction (amended by 0054; superseded in part by 0029) |
| [0029](0029-scope-replaces-tenant.md) | The core has no tenant: a scope is a `Policy` plus a hook from `velox/scope`, `WithoutPolicy` lifts it, the scope column is `Immutable`, and `WithShardFor` reads the context. (revised by 0038, 0039, 0054) |
| [0030](0030-generated-scope.md) | Superseded by 0038. A scoped column is marked `schema.Scoped(key)` in the schema; velox-gen writes the key (`OrgKey`) and each entity's scope into `scope_velox.go` and binds it around the entity's own `Policy` and `Hooks`, so it cannot be dropped. (revised by 0054; superseded by 0038) |
| [0031](0031-to-one-joins.md) | A query joins a to-one relation (`Join`, `LeftJoin`): the related entity is filled from the same row, `rel.Is` and `rel.By` filter and order by its columns, and the target's Read policy is in the ON clause. A to-many relation is refused. Amended 2026-11-22: `After` pages from a left join's missing row as NULL, and OrderVia reads its edge with a left join. Amended 2026-11-24: a left join to a denied target keeps every row, empty. (amended by 0143) |
| [0032](0032-ent-refusals.md) | What ent users write is generated: a zero Default, graphql.CreateDefault for a non-zero one, an OrderField on a nullable field with NULL last on every dialect, JSON lists as GraphQL lists; a Uint64 over 2^63-1 says why it is refused (reversed in part by 0045; withdrawn in part by 0082; the Uint64 refusal reversed 2026-11-24: the whole range is taken) |
| [0033](0033-graphql-inputs-not-mutations.md) | Methods, runtime and nulls superseded by 0045. velox-graphql generates `Create<T>Input` and `Update<T>Input` with their methods `Create(ctx, x)` and `Update(ctx, id, set...)`, run by a generic gqlimpl runtime, and no `type Mutation` and no delete: the application declares its mutations, as with entgql. (superseded in part by 0045, 0061) |
| [0034](0034-schema-declares-behaviour.md) | Superseded by 0039 but for the schema declaring behaviour and gen being all generated. An entity's `Policy` and `Hooks` are declared on its schema, typed with gen; velox-gen writes `gen/runtime` to bind them, an entity fails at first use when it is not linked, and the loader compiles the schema without them, so `gen/` is all generated and a stale one never blocks generation. (revised by 0036, 0037, 0038; superseded in part by 0039) |
| [0035](0035-untyped-runtime-for-generated-graphql.md) | Generated read surface revised by 0046. Generated GraphQL code runs on a non-generic gqlimpl over velox's untyped `Table` surface, "For generated code.", which builds the typed API's statements through the same engine and refuses another entity's conditions, rows and out-of-range values; a 100-entity `gen` compiles in 1.7 s instead of 7.2 s. (revised by 0046, 0051, 0052; superseded in part by 0061) |
| [0036](0036-split-gen-for-behaviour.md) | Layout superseded by 0037. A schema with `Policy` or `Hooks` splits gen: `gen/entity` holds the entities and does not import the schema, which imports it; `gen` re-exports every name and binds the schema in its `init`, so a program imports gen alone. `gen/runtime` and its blank import are gone; `gen/entity` alone fails at first use, and a schema that imports gen is refused. Revises 0034. (amended by 0050; superseded in part by 0037, 0039) |
| [0037](0037-ent-layout.md) | gen/runtime half superseded by 0039. ent's layout: every entity is in `gen`, always, with no `gen/entity` and no aliases. A schema that imports gen is not imported by it: `gen/runtime` binds its methods, defaults and validators by name, and a program imports it once, `import _ ".../gen/runtime"`, as ent's `ent/runtime`; without it a statement fails and names that line, and velox-gen warns of a module with no such import. gen/runtime is written only when something needs binding; the schema may not import it. Supersedes 0036's layout. (amended by 0065; revised by 0038, 0039) |
| [0038](0038-tenancy-is-a-mixin.md) | Revised by 0039. Tenancy is a mixin the application writes over package `scope`, bound before the entity's own; `schema.Scoped`, `scope_velox.go`, `Descriptor.Scope` and `velox.Scoper` are gone, and `scopetest.Isolates` checks an entity is confined. Supersedes 0030. (revised by 0039, 0054) |
| [0039](0039-untyped-behaviour.md) | Revised by 0040. Behaviour declared in the schema is untyped and names columns by name (then `velox.C("org_id").EQ(v)`, `velox.Edge("doc").Has()`), as ent's is; mixin methods are plain; gen imports the schema (then as `sch`, listing method values); the schema may not import gen; gen/runtime is gone; a hook that needs gen's types is a run-time `velox.WithHooks`. (amended by 0081; revised by 0040) |
| [0040](0040-schema-value-and-ent-names.md) | A descriptor names its schema's value, `Schema: schema.Issue{}`, and velox reads the mixins' and the schema's Policy, Hooks and Interceptors from it; gen imports the schema by its own name; conditions take ent's names (`velox.FieldEQ`, `velox.HasEdge`, `velox.HasEdgeWith`) over one `velox.Predicate`, an instance of `Pred`. Revises 0039. |
| [0041](0041-edges-struct.md) | An entity's relations are in an ent-style `Edges XEdges` struct, `json:"edges,omitzero"`; One and Many keep the loaded state, so there is no `loadedTypes` and no per-edge `OrErr`; `XEdges` joins velox-gen's top-level name check. |
| [0042](0042-plain-file-names.md) | An entity's generated file is `<entity>.go`, as ent names it, or `<entity>_velox.go` when go build would leave that name out of a build (`ab_test.go`, `server_linux.go`) or it is `velox.go`; velox-graphql's files keep `_gql.go` (amended by 0065) |
| [0043](0043-graphql-method-names.md) | velox-graphql names an edge's method after the edge (`Post.Author(ctx)`) and a Node's ID method `GlobalID`, as entgql's are; the SDL drops the `@goField` gqlgen no longer needs; no per-type `NodeGQL` or `KeyGQL`. Its Node and `GlobalID` are superseded by 0061 |
| [0044](0044-edge-setters.md) | A relation handle's `Add`, `Remove` and `Clear` are `Setter`s that `Insert` and `Update` write after the row, in one transaction, with gqlimpl's edge semantics moved into the core; a failure on keys is a `*velox.EdgeError` of `ErrNotFound` or `ErrLinked` |
| [0045](0045-graphql-input-setters.md) | A GraphQL input has one method, `Setters()`, plain Go that returns velox setters with no I/O; the resolver writes them with `db.Insert` or `db.Update` and reads the row back; an explicit null is a field not given; gqlimpl keeps only what Setters calls (amended by 0048, 0061) |
| [0046](0046-graphql-paginate.md) | A type's connection is `Paginate<Plural>(ctx, q, …)` of a query the resolver builds, as entgql's `Query().Paginate`; a where input's untyped condition is unexported; `gqlimpl.Conn` is `gqlimpl.Type`, described by `postGQL` (amended by 0049, 0061; revised by 0047) |
| [0047](0047-graphql-edge-source.md) | An edge method is one line: `(*gqlimpl.Type).Edge(x, rel)` passed to `EdgeOne`, `EdgeList` or the target's unexported `paginate<Plural>`, which `Paginate<Plural>` calls with `gqlimpl.Query(q)`; `Type.Edges` is by relation and names the field; a batch keys on the arguments Paginate got, `Args.Where` but not `Args.Pred` |
| [0048](0048-update-one.md) | `UpdateQuery.One` writes the one row its conditions match, under the Read and Write policies, and returns it read back by its key, as ent's `UpdateOne`; `veloxgql.DB(ctx)` panics where `DBFromContext` fails; `Setters()` keeps its error (amended by 0062, 0092) |
| [0049](0049-graphql-go-names.md) | A connection is `NewPostConnection(ctx, q, …)`, lazy, and its body has no plumbing (`Args.Order`, `gqlgraph.WhereOf`); the runtime is `veloxgql/gqlgraph`, after ent's `sqlgraph`; `postType`, `Column{Name, Index}`, `AlwaysRead`, `EdgeIDField`, `Validate`, `nodeKind`; receivers are named after their type (revised by 0059) |
| [0050](0050-handles-enum-haswith.md) | The handles' type is exported, `PostHandles`; an enum's handle is `velox.Col` (no Contains or Like); `Rel.HasWhere` is `Rel.HasWith`, as ent's `HasXWith` |
| [0051](0051-untyped-rows-are-any.md) | The untyped surface takes and returns a row as a *E in an any, checked against the Table's entity, not an unsafe.Pointer; `Table.Ptr` is gone; gqlgraph and gqlcore hold rows as any; the aggregates stay functions, as methods cost each entity package about 30 KB. Revises 0035 (amended by 0052) |
| [0052](0052-untyped-package.md) | The untyped surface is package `velox/untyped` (`untyped.TableOf`, `untyped.Query(db, t)`, `untyped.FromQuery(q)`, `untyped.MutationTable(m)`…); `velox.Meta` and `velox.Query` hold engine state that it reaches by a pointer conversion; `Typed` is gone; veloxgql Version19. Revises 0035 and 0051 |
| [0053](0053-engine-split.md) | `internal/engine` keeps its name; the drivers' errors are `internal/dberr`; rendering and routing stay, as `EntityInfo`, `Statement` and `Node` hold engine state. Amends 0020 |
| [0054](0054-fail-closed-runtime.md) | The runtime fails closed: `db.WithoutPolicy(reason)` returns a DB, and the context form is gone; a GraphQL edge batch is keyed by the SQL each caller's context reads; a pool's one connection is held by its Iter's or Tx's context, not a goroutine ID. Amends 0028 |
| [0055](0055-lazy-unsafe-scope.md) | `[_ Lazy[E]]` stays: without it one `Query[E]` adds 76× the bytes to a package and an entity package 3.1×; `unsafe` stays, with offsets from `fieldOf` and `-race`'s checkptr; routing and migrate stay, free for a DB that does not use them |
| [0056](0056-scale-round.md) | Keys of any type are tested on every dialect; `field.Int64("version").Version()` gives optimistic locking with `ErrStale`; overload, COPY, resharding, MySQL online DDL and an outbox stay outside velox; CockroachDB is not supported (NULL order) |

| [0058](0058-json-paths.md) | A JSON handle's `Text(keys...)`, `Number(keys...)`, `Bool(keys...)` and `HasKey(keys...)` read one kind of value at a path, NULL for any other, with each dialect's type test, so the same rows match on PostgreSQL, MySQL and SQLite; keys are arguments |

| [0060](0060-raw-rows.md) | `db.Rows(ctx, reason, sql, args...)` yields rows that are no entity's, to `Scan` in column order, on the DB's connection, a transaction's included, as `Raw`'s `Iter` runs |
| [0061](0061-graphql-plain-ids.md) | A GraphQL ID is the entity's key in its own Go type, which gqlgen decodes (`id int64` in a resolver), one key Go type per schema; `veloxgql.Int64ID` is the int64 ID; no Node, `node`, `nodes`, `GlobalID` or `DecodeID`; cursors stay opaque (amended by 0088, 0152; the compat=veloxe parts superseded by 0156) |

| [0063](0063-optional-needs-a-value.md) | Superseded by 0090. | [0064](0064-insert-null-literal.md) | Superseded by 0093. A nullable column that every row of an INSERT leaves NULL is written as the literal `NULL`, not a parameter per row; the column is still written, so a `DEFAULT` does not apply, and the shape key holds which columns are literal; 100 rows of 25 columns with 13 nil send 1,200 parameters, not 2,500, and run in 0.72 ms, not 1.03 ms, on PostgreSQL |
| [0065](0065-veloxgen-veloxschema-defaults.md) | `velox-gen` with no flags reads `./veloxschema` and writes `./veloxgen`, a package named `veloxgen`, not `./schema` and `./gen`: both old names clash with other packages a program holds; `-out` and `-package` still name any other; the generated code's shape is the same, so `GeneratedCodeIsVersionN` stays |
| [0066](0066-use-tx.md) | `vtx, err := velox.UseTx(db, tx)` returns a DB on a `*sql.Tx` the caller began, a function so `*sql.Tx` stays out of `DB`'s method set: the caller commits or rolls back and the DB fails once `tx` ends, nothing is retried and no `TxAround` hook runs, a nested `Tx` is a savepoint; veloxpgx and a sharded DB are refused |
| [0067](0067-allow-unbounded.md) | A read with no `Limit` is allowed by `AllowUnbounded()`, not `Unbounded()`: no popular Go ORM has a read guard or the word; gorm names its write opt-out `AllowGlobalUpdate`; the call only waives the check, so a `Limit` still applies; `ErrUnbounded` and `Statement.Unbounded` keep their names. | [0068](0068-graphql-enums-only.md) | `velox-gen -plugin velox-graphql:only=enums` writes only the `MarshalGQL` and `UnmarshalGQL` of velox-gen's enum types, for an application with its own SDL and gqlgen autobind: `open` goes out as `OPEN` and comes back as `open`; no `velox.graphql`; the marshalers stay out of velox-gen, as `graphql.EnumValues` renames are GraphQL's |
