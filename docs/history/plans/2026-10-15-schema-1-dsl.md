# Schema DSL, Plan 1: the DSL and the model — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the ent-style schema DSL (`schema`, `schema/field`, `schema/edge`, `schema/index`, `schema/mixin`). Ship the loader that turns a schema package into a versioned model, and the validator that resolves the model into a graph of entities, columns and relations. Add `velox-gen describe [-json]`, which prints that graph. Nothing in the runtime changes.

**Architecture:**
- **The DSL packages build descriptors.** The descriptor types live in `schema/internal/desc`, so that `schema` and the builder packages share them without an import cycle. The `schema` package aliases `desc.Annotation`.
- **`schema/load` is public.** It holds the JSON model (`Model`, `Schema`, `Field`, `Edge`, `Index`) and `Marshal`. A program that `internal/gen` writes into the user's module imports the user's schema package and `schema/load`, and prints the model.
- **`internal/gen` has three parts:**
  - `Load` runs that program;
  - `Build` checks the model against every rule in spec §4.2 and resolves it into a `Graph` (tables, Go names, ID fields, relation kinds and foreign-key columns, following ent's rules);
  - `Describe` prints the graph.
- **Plans 2–4 build on this one:**
  - plan 2: runtime metadata from generated literals, and typed hooks;
  - plan 3: the generator writing `gen/` from the `Graph`, and `contrib` plugins;
  - plan 4: the `dialect/pgx` split.

**Tech Stack:** Go 1.27, standard library only in the root module (`go/parser`, `go/ast`, `os/exec`, `encoding/json`, `reflect`); `internal/tempmod` for temp-module tests; `cmd/velox-gen` (its own module) gains a requirement on the root module.

**Spec:** `docs/history/specs/2026-10-15-schema-design.md` §1 and §4 (load, validate, `describe -json`). §2, §3, §5 and §6 belong to plans 2–4. The spec relies on `docs/history/specs/2026-10-14-core-design.md` §1 and the policy design `docs/history/specs/2026-10-14-policy-design.md` §2.1 (tenant rules).

## Global Constraints

- **Go 1.27.** `methods_test.go` (every method of a generic type is generic) parses the root package only. The schema packages are compiled into the loader program and, in plan 3, into `gen`. They are exempt, and their builders are ordinary generic types.
- **Nothing runs at program start** in any new package: no package-level variable is initialized by a function call (a `regexp.MustCompile` at package level is one), and there are no `init` functions.
- **The root module stays standard-library only.** `internal/gen` uses `go/parser`, not `golang.org/x/tools`.
- **Import graph.** Keep it acyclic:
  - `schema/internal/desc` imports only the standard library.
  - `schema` imports `desc`.
  - `schema/field`, `schema/edge` and `schema/index` import `desc` and `schema`.
  - `schema/mixin` imports `schema` and `schema/field`.
  - `schema/load` imports all of the above.
  - `internal/gen` imports `schema/load` and the standard library.
  - Nothing in the root package `velox` imports any of them in this plan.
- **Paths.**
  - The schema package's import path is `github.com/syssam/velox2/schema`, held as the constant `load.SchemaPath`.
  - The loader's own import path is `github.com/syssam/velox2/schema/load`.
- **Errors.**
  - `internal/gen` errors start `schema <Name>: ` and, when they are about one element, continue `field "<name>": `, `edge "<name>": ` or `index <i>: `.
  - `Build` returns every error it finds, joined, in a deterministic order: by schema name, then by the order of the rules in Task 5.
- **Determinism.** `Marshal`, `Build` and `describe -json` produce byte-identical output for the same input: no map iteration order reaches output unsorted.
- **Clean.**
  - `gofmt`, `go vet` and golangci-lint v2.14.0 are clean in the root module and `cmd/velox-gen`.
  - `go test -race ./...` passes in both.
  - Tests that build a temporary module skip under `-short`, as `compilecost_test.go` does.

## Rulings this plan makes on the spec

1. **The descriptor types live in `schema/internal/desc`.** `schema.Field` is `interface{ Descriptor() *desc.Field }`.
   - Why: the spec names `schema.Field` and `schema.Annotation` in one package. The builders need `Annotation`, and `schema.Field` needs the builders' descriptor, which is a cycle. An internal package breaks it, and keeps descriptors out of the 1.0 API.
   - If wrong: third parties cannot write a `schema.Field` of their own. That is intended, because the field kinds are a closed set.
2. **`field.UUID(name, typ driver.Valuer)` and `field.Other(name, typ driver.Valuer)` keep ent's signatures.** The spec's `field.UUID("id")` is shorthand. ent compatibility (success criterion 1) needs the type argument. If wrong: one argument too many.
3. **`Default` takes a value on bool, number, string, bytes, enum and JSON fields.** On time and UUID fields it takes a function (`field.Time("created_at").Default(time.Now)`), as in ent.
   - `DefaultFunc` and `UpdateDefault` take `any`, which must be a `func() T` of the field's Go type, as in ent, so that a `GoType` named type works.
   - A wrong function is a descriptor error.
4. **A bool or numeric field with a literal `Default` gets a pointer Go field** (`Graph` field `Pointer: true`), even without `Nillable`. Its column stays NOT NULL.
   - Why: Core §1 refuses a `Default` on a non-pointer bool or number, because an explicit `false` or `0` could not be told from "unset". ent schemas use `field.Bool("active").Default(true)` routinely, and success criterion 1 needs them to work.
   - `DefaultFunc` does not force a pointer: Core already treats the zero value as unset there.
   - If wrong: such fields are `*bool` where a user expected `bool`.
5. **Every foreign key is a field.**
   - An edge whose foreign key no declared field binds (`edge.Field`) gets an implicit field on the entity whose table holds the column, named after ent's column (`user_posts` → `UserPosts`).
   - It is required when the edge is `Required`, and `Optional` and `Nillable` otherwise.
   - Why: velox's runtime reads and writes columns through struct fields and has no hidden columns. ent's hidden foreign-key fields have no velox equivalent.
   - If wrong: one extra exported field per such edge.
6. **Relation kinds, tables and foreign-key column names follow ent's `resolve`.** That covers O2O, O2M, M2O and M2M; self-referential edges are bidirectional; join tables are `<owner label>_<edge name>`.
   - The default table is `plural(snake(Name))` ("users", "categories", "boxes"). That matches ent for regular nouns; an irregular one needs `schema.Table`.
   - `edge.Through` (edge schemas) is not offered.
   - If wrong: an irregular noun's table differs from ent's.
7. **The default ID is `field.Int64("id")`.** A declared field named `id` replaces it. It must be an integer, a string or a UUID type, and it may not be `Optional`, `Nillable` or have an `UpdateDefault`.
8. **Behaviour in a schema is refused.** A schema type with a `Hooks`, `Policy` or `Interceptors` method fails to load, with a message pointing to spec §3. Why: a ported ent schema would otherwise compile and silently lose its hooks and policy.
9. **Annotations merge by name.**
   - A later annotation of the same name replaces an earlier one, unless it implements `schema.Merger`.
   - Order: the mixins' annotations in mixin order, then the schema's own.
   - The model holds each annotation as its JSON encoding, keyed by `Name()`.
10. **`describe` prints the resolved `Graph`, not the raw model.** That is what the spec's "prints the model" means to a reader: tables, columns, relations. Plan 3's plugins get the same `Graph`. If wrong: the raw model is one `json.Marshal` away.

## Review Focus

1. **A ported ent schema with `Hooks()` or `Policy()`** must fail to load with a message, not silently drop behaviour (Ruling 8). Pinned in Task 4: `TestMarshalRefusesBehaviour`.
2. **`field.Bool("x").Default(true)` without `Nillable`,** which is ent-common, must load and resolve to a pointer field, not an error (Ruling 4). Pinned in Task 5: `TestBuildDefaultBoolIsPointer`.
3. **A schema package that does not compile, or whose `Fields()` panics,** must give an error naming the package or the schema, and leave no `.velox-gen-*` directory behind. Pinned in Task 6: `TestLoadCompileError`, `TestLoadPanicNamesSchema`, `TestLoadLeavesNoDirectory`.
4. **Self-referential edges,** a tree (`edge.To("children", Node.Type).From("parent").Unique()`) and a friends M2M, must resolve without duplicate columns, and deterministically. Pinned in Task 5: `TestBuildSelfReference`.
5. **Map-ordered inputs** (`SchemaType` maps, annotations) must not make `describe -json` differ between runs. Pinned in Task 7: `TestDescribeDeterministic`.

```go
package desc

type Annotation interface{ Name() string }

// GoType describes a Go type as the generator must write it.
type GoType struct {
	Ident   string   // as written in Go source, e.g. "[]string", "*schema.Info", "uuid.UUID"
	PkgPath string   // the named type's package; "" for builtin and unnamed composites of builtins
	Kind    string   // reflect.Kind's String(), of the type itself: "slice", "ptr", "struct", "string"…
	Imports []string // every package path the type mentions, sorted, without duplicates
}

func GoTypeOf(t reflect.Type) *GoType

type Check struct {
	Kind string // NotEmpty, MinLen, MaxLen, Match, Range, Min, Max, Positive, Negative, NonNegative
	Args []any  // MinLen/MaxLen: [int]; Match: [pattern string]; Range: [min, max]; Min/Max: [v]
}

type Enum struct{ Name, Value string } // Name is the Go name's suffix; Value is stored

type Field struct {
	Name          string
	Type          string // bool int int8 int16 int32 int64 uint uint8 uint16 uint32 uint64 float32 float64 string bytes time uuid json enum other
	Size          int    // max length; 0 for the dialect default; math.MaxInt32 for Text
	GoType        *GoType // nil: the standard type for Type
	RType         any     // the reflect.Type of the field's Go type, to check functions; never serialized
	Optional, Nillable, Immutable, Unique, Sensitive, Tenant bool
	Default       any // a value (or, on time and uuid, a func() T); nil when none
	DefaultFunc   any // a func() T; nil when none
	UpdateDefault any // a func() T; nil when none
	Enums         []Enum
	Checks        []Check
	Validators    []any // Validate's functions, each a func(T) error
	StorageKey    string
	SchemaType    map[string]string
	Comment       string
	StructTag     string
	Annotations   []Annotation
	Err           error // the first misuse of the builder
}

type Edge struct {
	Name, Type, TypePkg string // Type is the target schema's type name; TypePkg its package path
	Inverse              bool
	RefName              string // From(...).Ref(name)
	Ref                  *Edge  // To(...).From(name): the inverse declared inline
	Unique, Required, Immutable bool
	Field                string // the foreign-key field this edge binds
	Table                string
	Columns              []string
	Symbols              []string
	Comment              string
	Annotations          []Annotation
	Err                  error
}

type Index struct {
	Fields, Edges []string
	Unique        bool
	StorageKey    string
	Where         string
	Annotations   []Annotation
}
```

`PkgPath` is that of the type after stripping pointers, slices, arrays and maps' element only when the type itself is a pointer to a named type. Define it precisely as: the `PkgPath()` of the type, or for a pointer, of its element. `Imports` walks pointer, slice, array, map key and value, and chan elements, collecting `PkgPath()` of every named type.

- `Enum` `Default` not among the values (also checked at `Descriptor()`).

The typed part:

```go
// typed holds the options of a field whose values are of the Go type V.
type typed[B, V any] struct{ common[B] }

func (t typed[B, V]) Default(v V) B              { t.d.Default = v; return t.self }
func (t typed[B, V]) DefaultFunc(fn any) B       { t.d.DefaultFunc = fn; return t.self }
func (t typed[B, V]) UpdateDefault(fn any) B     { t.d.UpdateDefault = fn; return t.self }
func (t typed[B, V]) Validate(fn func(V) error) B {
	if fn == nil {
		fail(t.d, "Validate is given a nil function")
	} else {
		t.d.Validators = append(t.d.Validators, fn)
	}
	return t.self
}
// GoType makes the field's Go type that of typ, which must have the field's kind.
func (t typed[B, V]) GoType(typ any) B { setGoType(t.d, typ, reflect.TypeFor[V]()); return t.self }
```

The builders:
- `stringBuilder`, `bytesBuilder` and `boolBuilder` embed `typed[*X, V]`.
- `numberBuilder[T]` embeds `typed[*numberBuilder[T], T]`.
- `timeBuilder`, `uuidBuilder`, `jsonBuilder`, `enumBuilder` and `otherBuilder` embed `common[*X]` and declare their own `Default` (and `GoType` for enum).
- The constructor wires `self`, for example:

```go
func String(name string) *stringBuilder {
	b := &stringBuilder{}
	b.typed = typed[*stringBuilder, string]{common[*stringBuilder]{d: &desc.Field{Name: name, Type: "string", RType: reflect.TypeFor[string]()}, self: b}}
	return b
}
```

Each constructor sets `RType` to the field's standard Go type:

| Field type | Standard Go type |
|---|---|
| time | `time.Time` |
| bytes | `[]byte` |
| enum | `string` |
| json, uuid, other | the given value's `reflect.TypeOf`, with `GoType` set by `GoTypeOf` |

`numberBuilder[T]` has the constraint `int | int8 | int16 | int32 | int64 | uint | uint8 | uint16 | uint32 | uint64 | float32 | float64`. Its constructor's `Type` is `reflect.TypeFor[T]().Kind().String()`.

`setGoType(d, typ, base)`:
- a nil `typ` fails;
- if `reflect.TypeOf(typ).Kind() != base.Kind()` (`[]byte` compares as slice of uint8) it fails with "GoType %v has kind %s; the field needs %s";
- otherwise it sets `d.GoType = desc.GoTypeOf(t)` and `d.RType = t`.

`finish(d)` runs once per `Descriptor()` call and is idempotent:
- **Function options:** for each of `DefaultFunc`, `UpdateDefault`, and `Default` on time or uuid fields, the value must have `reflect.Func` kind, `NumIn() == 0`, `NumOut() == 1`, and an `Out(0)` assignable to `d.RType`. Otherwise it calls `fail(d, "%s must be a func() %v", option, d.RType)`.
- **Enums:** an enum `Default` must equal a value's `Value`.

Builtin checks append `desc.Check`:
- `MaxLen(n)` also sets `d.Size = n`;
- `Range(lo, hi)` records `Args: []any{lo, hi}`;
- `Match(re)` records `Args: []any{re.String()}`.

`enumBuilder`:
- `Values(vs...)` appends `{Name: v, Value: v}` per value;
- `NamedValues(pairs...)` with an odd count fails, and otherwise appends `{Name: pairs[i], Value: pairs[i+1]}`;
- `GoType(ev EnumValues)` sets `GoType` and `RType` from `ev` and appends `ev.Values()` as values;
- `Default(v string)` sets `d.Default = v`.

The JSON constructors:
- `JSON(name, typ)` with a nil `typ` fails, and otherwise sets `GoType` from `reflect.TypeOf(typ)`;
- `Strings`, `Ints` and `Floats` are `JSON(name, []string{})`, `JSON(name, []int{})` and `JSON(name, []float64{})`.

`doc.go` gets a package comment listing the field types and pointing to the schema design §1.1.

**How `Marshal` works:**
- **Per schema, in name order:**
  - Recover a panic in any of the schema's methods as an error: `schema User: Fields panicked: <value>`.
  - Refuse behaviour (Ruling 8): if `reflect.TypeOf(s)` has a method named `Hooks`, `Policy` or `Interceptors`, fail with `schema User: has a Hooks method; hooks and policies are methods on the generated entity (schema design §3), not in the schema`.
  - **Mixins, in order:** for mixin `i`, take its fields, edges and indexes with `Position{Index: j, MixedIn: true, MixinIndex: i}`. Merge its annotations into the schema's.
  - **Then the schema's own** fields, edges and indexes with `Position{Index: j}`, and its own annotations merged last.
- **A field:**
  - A nil entry fails: `schema User: Fields()[2] is nil`. Likewise for edges and indexes.
  - A descriptor `Err` fails: `schema User: <err>`; the error already names the field.
  - **Default:** a function value goes to `DefaultFunc: true`. Any other non-nil value goes to `Default`, as its `json.Marshal`.
  - `DefaultFunc` and `UpdateDefault` are recorded as booleans.
  - `Validators` is the count of custom validators.
  - `Checks`: each argument is passed through `json.Marshal`.
  - `GoType` is copied from the descriptor.
  - `Annotations` are merged as Ruling 9 says.
- **An edge:**
  - A descriptor `Err` fails.
  - An inline `Ref` becomes a second `load.Edge`, appended right after its assoc edge, with `Inline: true`, `Inverse: true`, `Ref: <assoc name>` and the same `Position`.
- **Annotation merging:**
  - The result is a `map[string]schema.Annotation`. Adding an annotation whose name is already in the map, when the new one implements `schema.Merger`, stores `new.Merge(old)`; otherwise the new one replaces the old.
  - Each annotation is then `json.Marshal`ed. An annotation that does not marshal is an error naming it.
- **Output:** `json.MarshalIndent(model, "", "  ")`. `encoding/json` sorts map keys, so the output is deterministic.

**Naming (`names.go`):**
- `snake("OrgID")` = `org_id`, `snake("HTTPServer")` = `http_server`: copy `cmd/velox-gen/names.go`'s `snake`.
- `plural` is copied from `cmd/velox-gen/names.go`.
- `pascal("org_id")` = `OrgID`. It splits on `_`. A word whose upper case is in ent's acronym list becomes upper case; otherwise its first letter is raised. The list:

  ```
  ACL API ASCII AWS CPU CSS DNS EOF GB GUID HCL HTML HTTP HTTPS ID IP JSON KB LHS MAC MB QPS RAM RHS RPC SLA SMTP SQL SSH SSO TCP TLS TTL UDP UI UID URI URL UTF8 UUID VM XML XMPP XSRF XSS
  ```

- `ident(s)` is `token.IsIdentifier(s) && !token.IsKeyword(s)`.

**`Build`'s order of work:**
1. One `Entity` per schema:
   - `Label = snake(Name)`.
   - `Table`, and `TableSchema` from the `Table` annotation; the default table is `plural(Label)`.
   - The fields with `GoName = pascal(Name)` and `Column = StorageKey` (or `Name`).
   - `Pointer = Nillable || (literal Default && Type is bool or numeric)`.
2. **The ID:** a declared field named `id` is moved to `Fields[0]`. Otherwise velox prepends `{Name: "id", Type: "int64", GoName: "ID", Column: "id", AutoID: true}`.
3. **Edges** follow ent's `resolve`, quoted in the plan's Ruling 6; Step 3 below gives the code.
4. **Implicit foreign keys** (Ruling 5): for each non-M2M relation, find the entity whose table is `Rel.Table`, and the edge on that entity's side. If the edge binds a `Field`, `Edge.Field` names it. Otherwise velox adds a field to that entity:
   - `Name` is `Rel.Columns[0]`;
   - `Type` is the referenced ID's `Type`, and `GoType` is the ID's;
   - `Optional` and `Nillable` unless the edge on that side is `Required`;
   - `Implicit` is the edge's name.

   Both edges of the pair get `Field` set to the field's name. Implicit fields are appended after the declared ones, in edge order.

   The foreign key references the ID of the entity on the other side from the table that holds it:
   - for an O2M, or an M2O inverse, the "one" side's ID;
   - for an O2O, the assoc edge owner's ID;
   - for an M2O assoc (a Unique `To` with no inverse), the target's ID.
5. **Indexes:**
   - `Columns` are the named fields' columns, then the named edges' foreign-key columns.
   - `Name` is `StorageKey`, or `<table>_<col1>_<col2>…`.
   - A field `Unique()` adds no `Index`; the generator and planner read `Field.Unique`.
6. **Every rule below.** Errors are collected, not returned at the first.

```go
func (b *builder) resolve(e *Entity, le *load.Edge, ed *Edge) {
	t := b.g.Entity(le.Type)
	switch {
	case le.Inverse:
		ref := t.assoc(le.Ref) // the load.Edge and *Edge on t named le.Ref, non-inverse
		// rules 6–9 checked here
		ed.Ref, refEdge.Ref = refEdge.Name, ed.Name
		table, column := e.Table, t.Label+"_"+snake(ref.Name)
		switch a, b := ref.Unique, le.Unique; {
		case a && b:
			ed.Rel.Kind, refEdge.Rel.Kind = "O2O", "O2O"
		case !a && b:
			ed.Rel.Kind, refEdge.Rel.Kind = "M2O", "O2M"
		case a && !b:
			ed.Rel.Kind, refEdge.Rel.Kind = "O2M", "M2O"
			table = t.Table
		default:
			ed.Rel.Kind, refEdge.Rel.Kind = "M2M", "M2M"
			table = t.Label + "_" + ref.Name
			c1, c2 := t.Label+"_id", e.Label+"_id"
			if c1 == c2 {
				c2 = singular(le.Name) + "_id"
			}
			ed.Rel.Columns, refEdge.Rel.Columns = []string{c2, c1}, []string{c1, c2}
		}
		// …tables and single columns as in ent
	case refEdge == nil: // an assoc edge with no inverse: ent's second switch
	}
}
```

### Task 6: `internal/gen`: `Load` runs the schema package

**Files:**
- Create: `internal/gen/load.go`
- Test: `internal/gen/load_test.go`, `internal/gen/discover_test.go`

**Interfaces:**
- Consumes: `load.Marshal`, `load.Model`, `load.Version`, `load.SchemaPath` (Task 4); `internal/tempmod` (existing: `tempmod.Write(dir, repo string, files map[string]string) error`, `tempmod.Go(dir string, args ...string) (string, error)`).
- Produces:

```go
// Load loads the schema package that pattern names, from the module that
// holds dir, by compiling and running a program that marshals its schemas.
// env is the environment of the go commands it runs; nil means os.Environ().
func Load(dir, pattern string, env []string) (*load.Model, error)

// discover returns the exported struct types of the package's files that
// embed schema.Schema, sorted, and an error for an unexported one.
func discover(files map[string][]byte) ([]string, error)
```

**How `Load` works:**
1. Run `go list -json=ImportPath,Name,Dir,GoFiles,Module,Error <pattern>` in `dir` with `env`.
   - Decode one package. A second object in the stream is an error: `velox-gen: <pattern> names more than one package; name the schema package`.
   - A package `Error` becomes an error.
   - A `Module` of nil is an error: `the schema package must be in a module`.
2. Read `GoFiles` from `Dir` and call `discover`. No schemas is an error: `no schemas in <importpath>: a schema is a struct that embeds schema.Schema`.
3. `os.MkdirTemp(Module.Dir, ".velox-gen-")`, then a deferred `os.RemoveAll`. Write `main.go`:

   ```go
   // Code generated by velox-gen, which deletes it after running.

   package main

   import (
   	"fmt"
   	"os"

   	"github.com/syssam/velox2/schema"
   	"github.com/syssam/velox2/schema/load"
   	s "<importpath>"
   )

   func main() {
   	b, err := load.Marshal("<importpath>", []schema.Interface{s.A{}, s.B{}}...)
   	if err != nil {
   		fmt.Fprintln(os.Stderr, err)
   		os.Exit(1)
   	}
   	os.Stdout.Write(b)
   }
   ```

   `go run ./<base>` it in `Module.Dir` with `env`. On failure the error is `loading <importpath>:\n<stderr>`, with the temporary directory's path replaced by `velox-gen` so the message is stable.
4. Decode stdout into `load.Model`. A `Version` other than `load.Version` is an error: `the loader wrote model version N; velox-gen reads version 1: update velox-gen and the velox2 module together`.

**How `discover` works:** parse each file with `parser.ParseFile(fset, name, src, parser.SkipObjectResolution)`.
- Find the local name of the import `load.SchemaPath`: its alias, or `schema`. A dot or underscore import does not count.
- Each `type X struct{...}` with an embedded field (no names) whose type is the `SelectorExpr` `<local>.Schema` is a schema.
- An unexported `X` is an error: `schema type x is unexported; a schema must be exported`.
