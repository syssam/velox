# Core 2 — The Generator — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `velox-gen`, the command that writes each entity's `<entity>_velox.go`, plus `velox-gen -check` for CI and `velox-gen verify`, which builds every entity's metadata and reports mistakes in `Schema` and `Mixin` methods before they reach production.

**Architecture:** `cmd/velox-gen` is its own Go module (`github.com/syssam/velox2/cmd/velox-gen`), so that applications using the library never depend on `golang.org/x/tools`. It does not import the library: it loads packages with `go/packages`, finds entities with `go/types` exactly as the runtime's `flatten` would see them, renders text, and gofmts it. A run first plans every file in memory and writes nothing if any entity has a problem. `verify` writes a throwaway `main` package into the module (`.velox-verify-*`, which `./...` ignores) that calls a new library function, `velox.CheckEntity`, for every entity. The library also gains the schema validation that plan 1's reviews deferred to here.

**Tech Stack:** Go 1.27, `golang.org/x/tools/go/packages` v0.52.0, `go/types`, `go/format`.

**Spec:** `docs/history/specs/2026-10-14-core-design.md`. Read §1 (entity rules), §2 (generated code: the file, handle types, generator rules) and §3 rule 4. Also read `docs/history/plans/2026-10-14-core-1-followups.md`: this plan resolves its "Plan 2" items and two "Before plan 3" items.

**This is plan 2 of 5 for Core.** Plan 1 (querying) is merged on `main`.

## Global Constraints

- The root module's dependencies stay as they are: pgx, plus go-sql-driver/mysql and modernc.org/sqlite for tests. `velox-gen` is a separate module, `github.com/syssam/velox2/cmd/velox-gen`, at `go 1.27.0`. Its only requirement is `golang.org/x/tools v0.52.0` (and what that pulls in), and it never imports `github.com/syssam/velox2`.
- Every generated file starts with exactly this line: `// Code generated by velox-gen. DO NOT EDIT.` velox-gen deletes a file only when it starts with that line. It refuses to overwrite a file without it.
- If any entity in the run has a problem, velox-gen writes nothing and exits 1. Every message it prints starts with `velox-gen: `.
- The generated file has the exact form of `internal/testmodel/invoice_velox.go`, which velox-gen must reproduce byte for byte.
- Handle choice (spec §2):
  - A pointer `*T` takes the `Null` form of `T`'s handle, and its value type is `T`.
  - `time.Time`, and types given with `-ordered`, take `OrderedCol`.
  - Integers, floats, `github.com/shopspring/decimal.Decimal`, and types given with `-number`, take `NumberCol`.
  - Strings take `StringCol`.
  - Everything else takes `Col`.
  - Named types are judged by their underlying type.
- Names:
  - The handles variable is the entity's plural, by these rules in order: a consonant followed by `y` becomes `ies`; `s`, `x`, `z`, `ch` and `sh` take `es`; everything else takes `s`. A `//velox:handle Name` comment on the type overrides it.
  - The `MetaOnce` variable is `lowerCamel(Entity)+"Meta"` and the shape function is `lowerCamel(Entity)+"Shape"`.
  - The file is `snake(Entity)+"_velox.go"`, beside the file that declares the entity.
  - A collision with any non-generated declaration in the package, or between two entities, is a problem.
- An entity is a struct type that declares `func (x *T) Schema(s *velox.Schema)` itself. A method named `Schema` with any other parameter is not velox's and is ignored. velox's own form with a value receiver, or with results, is a problem.
- Relation handles (`OneRel`/`ManyRel`) are not generated until plan 4. `Shape.Relations` lists relation fields now.
- Library rules from plan 1 still hold:
  - Every method of a generic velox type is a generic method.
  - Errors velox creates start with `velox: `.
  - The §8 allocation budget test must pass.
- Tools: golangci-lint v2.14.0 through `go run`, and Go 1.27, as in `scripts/ci-local.sh`.

## Review Focus

1. **Regenerating after a rename.** A package whose generated file is out of date, because a field was renamed and the old file no longer compiles, must still regenerate cleanly. Pinned by `TestRegeneratesAfterARename` in Task 4.
2. **Unrelated `Schema` methods.** A type with a method named `Schema` that is not velox's (for example `Schema() string`) is neither an entity nor a problem. Pinned by the `notentity` case of `TestDiscovery` in Task 2.
3. **Import-name collisions.** A field type whose package name is also a package-level identifier in the entity's package must be imported under another name, and the file must still be valid Go. Pinned by `TestImportNamesAvoidThePackagesIdentifiers` in Task 3.
4. **Entities `verify` cannot reach.** `verify` cannot name an unexported entity, or one in package `main`, from another package. It must skip them with a note rather than fail to compile. Pinned by `TestVerifySkipsEntitiesItCannotName` in Task 5.
5. **No leftovers from `verify`.** `verify` must leave no `.velox-verify-*` directory behind, whether the entities pass, report errors, or fail to compile. Pinned by `TestVerifyLeavesNothingBehind` in Task 5.

```go
// fieldAt names the field of t at offset off with type ft, descending into
// embedded and nested structs ("stamps.UpdatedAt"); "" when there is none.
func fieldAt(t reflect.Type, off uintptr, ft reflect.Type) string {
	for i := range t.NumField() {
		f := t.Field(i)
		if f.Offset == off && f.Type == ft {
			return f.Name
		}
		if f.Type.Kind() == reflect.Struct && off >= f.Offset && off < f.Offset+f.Type.Size() {
			if n := fieldAt(f.Type, off-f.Offset, ft); n != "" {
				return f.Name + "." + n
			}
		}
	}
	return ""
}
```

```go
// validate refuses metadata that would render wrong SQL: two columns of one
// name, and a key or index that names no field or one field twice.
func validate(info *EntityInfo) error {
	var errs []error
	fail := func(field, format string, args ...any) {
		errs = append(errs, &SchemaError{Entity: info.Name, Field: field, Reason: fmt.Sprintf(format, args...)})
	}
	seen := make(map[string]int, len(info.Columns))
	for i, c := range info.Columns {
		if j, ok := seen[c.Name]; ok {
			fail(c.Field, "column name %q is also the name of %s", c.Name, info.Columns[j].Field)
			continue
		}
		seen[c.Name] = i
	}
	set := func(what string, cols []int) {
		if len(cols) == 0 {
			fail("", "%s names no fields", what)
			return
		}
		named := make(map[int]bool, len(cols))
		for _, c := range cols {
			if named[c] {
				fail(info.Columns[c].Field, "%s names the field twice", what)
			}
			named[c] = true
		}
	}
	set("the primary key", info.PrimaryKey)
	for _, ix := range info.Indexes {
		if ix.Unique {
			set("a unique index", ix.Columns)
		} else {
			set("an index", ix.Columns)
		}
	}
	return errors.Join(errs...)
}

// CheckEntity builds entity E's metadata and returns the error it holds, if
// any: a mistake in its Schema or Mixin methods, or generated code that is
// out of date. velox-gen verify calls it for every entity.
func CheckEntity[E any, PE Entity[E]]() error { return PE(nil).VeloxMeta().err }
```

```go
package main

import (
	"fmt"
	"go/token"
	"go/types"

	"golang.org/x/tools/go/packages"
)

// veloxPath is the import path of the velox library.
const veloxPath = "github.com/syssam/velox2"

// header is the first line of every file velox-gen writes. velox-gen deletes
// a file that starts with it when no entity produces that file any more, and
// never overwrites a file that does not.
const header = "// Code generated by velox-gen. DO NOT EDIT."

// entity is a struct velox-gen writes a file for.
type entity struct {
	pkg       *packages.Package
	name      string // the Go type name, e.g. "Invoice"
	file      string // the file that declares it
	pos       token.Position
	columns   []column
	relations []string
	handles   string // the handles variable, e.g. "Invoices"
	meta      string // the MetaOnce variable, e.g. "invoiceMeta"
	shape     string // the function returning the Shape, e.g. "invoiceShape"
	out       string // the generated file's path
}

// column is one column of an entity, in the runtime's order.
type column struct {
	field  string     // the field's name; fields of embedded structs flatten in
	handle string     // the handle type in package velox, e.g. "NumberCol"
	value  types.Type // the handle's value type V
}

// problem is a reason velox-gen refuses to write anything.
type problem struct {
	pos token.Position
	msg string
}

func (p problem) String() string {
	if p.pos.IsValid() {
		return fmt.Sprintf("%s: %s", p.pos, p.msg)
	}
	return p.msg
}

// config is what the command line sets.
type config struct {
	dir     string          // the directory package patterns are relative to
	env     []string        // the environment of go commands; nil inherits
	ordered map[string]bool // types, as "import/path.Name", with ordered handles
	number  map[string]bool // types, as "import/path.Name", with number handles
}
```

`cmd/velox-gen/load.go`:

```go
package main

import (
	"bufio"
	"fmt"
	"os"

	"golang.org/x/tools/go/packages"
)

const loadMode = packages.NeedName | packages.NeedFiles | packages.NeedSyntax |
	packages.NeedTypes | packages.NeedTypesInfo | packages.NeedModule

// load loads the packages the patterns name. Type errors are tolerated: a
// generated file that is out of date may not compile, and regenerating it is
// the point. A pattern that matches no files, and a file that does not parse,
// are errors.
func load(cfg config, patterns []string) ([]*packages.Package, error) {
	ps, err := packages.Load(&packages.Config{Mode: loadMode, Dir: cfg.dir, Env: cfg.env}, patterns...)
	if err != nil {
		return nil, err
	}
	if len(ps) == 0 {
		return nil, fmt.Errorf("no packages match %v", patterns)
	}
	for _, p := range ps {
		for _, e := range p.Errors {
			if e.Kind == packages.ParseError || (e.Kind == packages.ListError && len(p.GoFiles) == 0) {
				return nil, fmt.Errorf("%s: %s", p.PkgPath, e.Msg)
			}
		}
	}
	return ps, nil
}

// isGenerated reports whether the file at path starts with velox-gen's header.
func isGenerated(path string) bool {
	f, err := os.Open(path)
	if err != nil {
		return false
	}
	defer func() { _ = f.Close() }()
	line, _ := bufio.NewReader(f).ReadString('\n')
	return line == header+"\n"
}
```

```go
// discover finds the entities of pkg: struct types that declare
// func (x *T) Schema(s *velox.Schema) themselves. They come in name order, so
// output is deterministic.
func discover(pkg *packages.Package, cfg config) ([]*entity, []problem) {
	var ents []*entity
	var probs []problem
	scope := pkg.Types.Scope()
	for _, name := range scope.Names() {
		tn, ok := scope.Lookup(name).(*types.TypeName)
		if !ok || tn.IsAlias() {
			continue
		}
		named, ok := tn.Type().(*types.Named)
		if !ok {
			continue
		}
		found, why := declares(named, "Schema")
		if !found {
			continue
		}
		pos := pkg.Fset.Position(tn.Pos())
		if why != "" {
			probs = append(probs, problem{pos, name + ": " + why})
			continue
		}
		if named.TypeParams().Len() > 0 {
			probs = append(probs, problem{pos, name + " has type parameters; a velox entity cannot be generic"})
			continue
		}
		st, ok := named.Underlying().(*types.Struct)
		if !ok {
			probs = append(probs, problem{pos, name + " has a Schema method but is not a struct"})
			continue
		}
		e := &entity{pkg: pkg, name: name, file: pos.Filename, pos: pos}
		w := &walker{cfg: cfg, pkg: pkg, e: e, seen: map[string]bool{}}
		w.fields(st, 1)
		probs = append(probs, w.probs...)
		ents = append(ents, e)
	}
	return ents, probs
}

// declares reports whether t itself declares velox's method name: one
// *velox.Schema parameter. A method of that name with other parameters is not
// velox's and is not found. When velox's method has a value receiver or
// results, why says so.
func declares(t *types.Named, name string) (found bool, why string) {
	for i := range t.NumMethods() {
		m := t.Method(i)
		if m.Name() != name {
			continue
		}
		sig := m.Type().(*types.Signature)
		if sig.Params().Len() != 1 || !isSchemaPointer(sig.Params().At(0).Type()) {
			return false, ""
		}
		want := fmt.Sprintf("velox needs func (x *%s) %s(s *velox.Schema)", t.Obj().Name(), name)
		if _, ptr := sig.Recv().Type().(*types.Pointer); !ptr {
			return true, name + " has a value receiver; " + want
		}
		if sig.Results().Len() != 0 {
			return true, name + " returns values; " + want
		}
		return true, ""
	}
	return false, ""
}

func isSchemaPointer(t types.Type) bool {
	p, ok := types.Unalias(t).(*types.Pointer)
	if !ok {
		return false
	}
	n, ok := types.Unalias(p.Elem()).(*types.Named)
	return ok && n.Obj().Pkg() != nil && n.Obj().Pkg().Path() == veloxPath && n.Obj().Name() == "Schema"
}

// walker collects an entity's columns and relations exactly as the runtime's
// flatten does (meta.go): a field tagged velox:"-" is skipped, an embedded
// struct flattens in, an unexported field is skipped, a velox.One or
// velox.Many field is a relation, and every other field is a column.
type walker struct {
	cfg   config
	pkg   *packages.Package
	e     *entity
	seen  map[string]bool
	probs []problem
}

func (w *walker) fail(v *types.Var, format string, args ...any) {
	w.probs = append(w.probs, problem{w.pkg.Fset.Position(v.Pos()), w.e.name + ": " + fmt.Sprintf(format, args...)})
}

func (w *walker) fields(st *types.Struct, depth int) {
	for i := range st.NumFields() {
		f := st.Field(i)
		switch {
		case reflect.StructTag(st.Tag(i)).Get("velox") == "-":
		case f.Embedded() && flattens(f.Type()):
			w.embedded(f, depth)
		case !f.Exported():
		case relation(f.Type()):
			w.add(f)
			w.e.relations = append(w.e.relations, f.Name())
		default:
			w.add(f)
			w.column(f)
		}
	}
}

// flattens reports an embedded field the runtime does not treat as a plain
// field: a pointer (refused) or a struct (flattened in).
func flattens(t types.Type) bool {
	if _, ok := types.Unalias(t).(*types.Pointer); ok {
		return true
	}
	_, ok := t.Underlying().(*types.Struct)
	return ok
}

func (w *walker) embedded(f *types.Var, depth int) {
	t := types.Unalias(f.Type())
	if _, ok := t.(*types.Pointer); ok {
		w.fail(f, "embedded pointer %s is not supported; embed the struct itself", f.Name())
		return
	}
	mixin := false
	if n, ok := t.(*types.Named); ok {
		var why string
		if mixin, why = declares(n, "Mixin"); why != "" {
			w.fail(f, "%s's %s", f.Name(), why)
		}
	}
	if mixin && depth > 1 {
		w.fail(f, "mixin %s is inside another embedded struct, where velox does not call its Mixin method; embed it in the entity", f.Name())
	}
	before := len(w.seen)
	w.fields(t.Underlying().(*types.Struct), depth+1)
	if !mixin && len(w.seen) == before {
		w.fail(f, "embedded %s adds no columns; embed a struct only to share columns, or give the field a name", f.Name())
	}
}

// add records a field's name: two fields of one name (the entity's own and an
// embedded struct's) would be two columns of one name.
func (w *walker) add(f *types.Var) {
	if w.seen[f.Name()] {
		w.fail(f, "two fields are named %s (one in an embedded struct); velox needs one field per name", f.Name())
	}
	w.seen[f.Name()] = true
}

func (w *walker) column(f *types.Var) {
	if !resolved(f.Type()) {
		w.fail(f, "the type of %s cannot be resolved; fix the errors of the package that declares it", f.Name())
		return
	}
	h, v := classify(f.Type(), w.cfg)
	w.e.columns = append(w.e.columns, column{field: f.Name(), handle: h, value: v})
}

// relation reports a velox.One or velox.Many field.
func relation(t types.Type) bool {
	n, ok := types.Unalias(t).(*types.Named)
	if !ok {
		return false
	}
	o := n.Origin().Obj()
	return o.Pkg() != nil && o.Pkg().Path() == veloxPath && (o.Name() == "One" || o.Name() == "Many")
}

// resolved reports whether a type has no invalid part; go/types puts one
// where a package does not type-check.
func resolved(t types.Type) bool {
	switch t := types.Unalias(t).(type) {
	case *types.Basic:
		return t.Kind() != types.Invalid
	case *types.Pointer:
		return resolved(t.Elem())
	case *types.Slice:
		return resolved(t.Elem())
	case *types.Array:
		return resolved(t.Elem())
	case *types.Map:
		return resolved(t.Key()) && resolved(t.Elem())
	}
	return true
}
```

```go
package main

import "go/types"

// classify picks a column's handle type from its field's type (design §2): a
// pointer takes the Null form of its element's handle, whose value type is
// the element.
func classify(t types.Type, cfg config) (handle string, value types.Type) {
	if p, ok := types.Unalias(t).(*types.Pointer); ok {
		h, v := level(p.Elem(), cfg)
		return "Null" + h, v
	}
	return level(t, cfg)
}

// level is the handle of a type that is not a pointer: OrderedCol for
// time.Time and types registered as ordered; NumberCol for decimal.Decimal,
// types registered as numbers, and integers and floats; StringCol for
// strings; Col for everything else. Named types go by their underlying type.
func level(t types.Type, cfg config) (string, types.Type) {
	if n, ok := types.Unalias(t).(*types.Named); ok {
		switch id := typeID(n); {
		case id == "time.Time" || cfg.ordered[id]:
			return "OrderedCol", t
		case id == "github.com/shopspring/decimal.Decimal" || cfg.number[id]:
			return "NumberCol", t
		}
	}
	if b, ok := t.Underlying().(*types.Basic); ok {
		switch {
		case b.Info()&types.IsString != 0:
			return "StringCol", t
		case b.Info()&(types.IsInteger|types.IsFloat) != 0:
			return "NumberCol", t
		}
	}
	return "Col", t
}

// typeID names a named type as the -ordered and -number flags do:
// "import/path.Name".
func typeID(n *types.Named) string {
	o := n.Origin().Obj()
	if o.Pkg() == nil {
		return o.Name()
	}
	return o.Pkg().Path() + "." + o.Name()
}
```

```go
package main

import (
	"fmt"
	"go/ast"
	"go/token"
	"path/filepath"
	"strings"
	"unicode"

	"golang.org/x/tools/go/packages"
)

// plural names an entity's handles variable: Invoice → Invoices, Category →
// Categories, Box → Boxes, Day → Days.
func plural(s string) string {
	switch {
	case len(s) > 1 && s[len(s)-1] == 'y' && !strings.ContainsRune("aeiouAEIOU", rune(s[len(s)-2])):
		return s[:len(s)-1] + "ies"
	case strings.HasSuffix(s, "s"), strings.HasSuffix(s, "x"), strings.HasSuffix(s, "z"),
		strings.HasSuffix(s, "ch"), strings.HasSuffix(s, "sh"):
		return s + "es"
	}
	return s + "s"
}

// lowerCamel lowers an identifier's leading capitals: Invoice → invoice,
// ID → id, URLRecord → urlRecord.
func lowerCamel(s string) string {
	r := []rune(s)
	n := 0
	for n < len(r) && unicode.IsUpper(r[n]) {
		n++
	}
	if n > 1 && n < len(r) {
		n-- // the last capital starts the next word: URLRecord
	}
	for i := range n {
		r[i] = unicode.ToLower(r[i])
	}
	return string(r)
}

// snake is the snake_case of an identifier, for file names. It is the
// library's rule (names.go in package velox), which this module cannot import.
func snake(s string) string {
	lower := func(c byte) bool { return 'a' <= c && c <= 'z' || '0' <= c && c <= '9' }
	upper := func(c byte) bool { return 'A' <= c && c <= 'Z' }
	var b strings.Builder
	for i := range len(s) {
		c := s[i]
		if upper(c) {
			if i > 0 && (lower(s[i-1]) || upper(s[i-1]) && i+1 < len(s) && lower(s[i+1])) {
				b.WriteByte('_')
			}
			c += 'a' - 'A'
		}
		b.WriteByte(c)
	}
	return b.String()
}

// handleDirective returns the name a //velox:handle Name comment on the
// entity's type declaration sets, or "".
func handleDirective(pkg *packages.Package, name string) string {
	for _, f := range pkg.Syntax {
		for _, d := range f.Decls {
			gd, ok := d.(*ast.GenDecl)
			if !ok || gd.Tok != token.TYPE {
				continue
			}
			for _, s := range gd.Specs {
				ts := s.(*ast.TypeSpec)
				if ts.Name.Name != name {
					continue
				}
				for _, doc := range []*ast.CommentGroup{ts.Doc, gd.Doc} {
					if doc == nil {
						continue
					}
					for _, c := range doc.List {
						if v, ok := strings.CutPrefix(c.Text, "//velox:handle "); ok {
							return strings.TrimSpace(v)
						}
					}
				}
			}
		}
	}
	return ""
}

// name gives a package's entities their identifiers and file, and reports any
// that collide with each other or with the package's own declarations.
// Declarations in generated files do not count: they are about to be rewritten.
func name(pkg *packages.Package, ents []*entity) []problem {
	var probs []problem
	taken := map[string]string{} // identifier or file → the entity that has it
	claim := func(e *entity, what, id string) {
		if other, ok := taken[id]; ok {
			probs = append(probs, problem{e.pos, fmt.Sprintf("%s: its %s %s is also %s's; rename one of them", e.name, what, id, other)})
			return
		}
		taken[id] = e.name
		if obj := pkg.Types.Scope().Lookup(id); obj != nil {
			if at := pkg.Fset.Position(obj.Pos()); !isGenerated(at.Filename) {
				probs = append(probs, problem{e.pos, fmt.Sprintf("%s: its %s %s is already declared at %s; set another with //velox:handle Name", e.name, what, id, at)})
			}
		}
	}
	for _, e := range ents {
		e.handles = plural(e.name)
		if d := handleDirective(pkg, e.name); d != "" {
			if !token.IsIdentifier(d) {
				probs = append(probs, problem{e.pos, fmt.Sprintf("%s: //velox:handle %q is not an identifier", e.name, d)})
				continue
			}
			e.handles = d
		}
		e.meta = lowerCamel(e.name) + "Meta"
		e.shape = lowerCamel(e.name) + "Shape"
```

```go
// imports chooses the names a generated file gives the packages it imports,
// avoiding the names the entity's package already declares.
type imports struct {
	self  *types.Package
	names map[string]string // import path → the name the file uses
	decl  map[string]string // import path → the package's own name
	used  map[string]bool
}

func newImports(self *types.Package) *imports {
	return &imports{self: self, names: map[string]string{}, decl: map[string]string{}, used: map[string]bool{}}
}

// name returns the name the file uses for the package at path, whose own
// name is pkgName, and imports it.
func (im *imports) name(path, pkgName string) string {
	if n, ok := im.names[path]; ok {
		return n
	}
	n := pkgName
	for i := 2; im.used[n] || im.self.Scope().Lookup(n) != nil; i++ {
		n = pkgName + strconv.Itoa(i)
	}
	im.names[path], im.decl[path], im.used[n] = n, pkgName, true
	return n
}

// qualifier is the types.Qualifier of the generated file.
func (im *imports) qualifier(p *types.Package) string {
	if p.Path() == im.self.Path() {
		return ""
	}
	return im.name(p.Path(), p.Name())
}

// write writes the import block: the standard library, then the rest.
func (im *imports) write(b *bytes.Buffer) {
	var std, other []string
	for p := range im.names {
		if strings.Contains(strings.Split(p, "/")[0], ".") {
			other = append(other, p)
		} else {
			std = append(std, p)
		}
	}
	sort.Strings(std)
	sort.Strings(other)
	b.WriteString("import (\n")
	for i, group := range [][]string{std, other} {
		if i == 1 && len(std) > 0 && len(other) > 0 {
			b.WriteString("\n")
		}
		for _, p := range group {
			if im.names[p] != im.decl[p] {
				fmt.Fprintf(b, "\t%s %q\n", im.names[p], p)
			} else {
				fmt.Fprintf(b, "\t%q\n", p)
			}
		}
	}
	b.WriteString(")\n")
}

func quoted(ss []string) string {
	q := make([]string, len(ss))
	for i, s := range ss {
		q[i] = strconv.Quote(s)
	}
	return strings.Join(q, ", ")
}

// render returns the source of an entity's generated file (design §2).
func render(e *entity) ([]byte, error) {
	im := newImports(e.pkg.Types)
	vx := im.name(veloxPath, "velox")
	E := e.name
	handle := func(c column) string {
		return fmt.Sprintf("%s.%s[%s, %s]", vx, c.handle, E, types.TypeString(c.value, im.qualifier))
	}
	fields := make([]string, len(e.columns))
	for i, c := range e.columns {
		fields[i] = c.field
	}

	var b bytes.Buffer
	fmt.Fprintf(&b, "// Fails to compile if this file and the velox library disagree.\nconst _ = %s.GeneratedCodeIsVersion1\n\n", vx)
	fmt.Fprintf(&b, "// %s holds the typed handles of %s's columns and relations.\nvar %s = struct {\n", e.handles, E, e.handles)
	for _, c := range e.columns {
		fmt.Fprintf(&b, "\t%s %s\n", c.field, handle(c))
	}
	b.WriteString("}{\n")
	for i, c := range e.columns {
		fmt.Fprintf(&b, "\t%s: %s{I: %d},\n", c.field, handle(c), i)
	}
	b.WriteString("}\n\n")
	fmt.Fprintf(&b, "var %s %s.MetaOnce[%s]\n\n", e.meta, vx, E)
	fmt.Fprintf(&b, "// VeloxMeta is called by velox, not by applications.\nfunc (*%s) VeloxMeta() *%s.Meta[%s] { return %s.Get(%s) }\n\n", E, vx, E, e.meta, e.shape)
	fmt.Fprintf(&b, "func %s() %s.Shape[%s] {\n\treturn %s.Shape[%s]{\n\t\tColumns: []string{%s},\n", e.shape, vx, E, vx, E, quoted(fields))
	if len(e.relations) > 0 {
		fmt.Fprintf(&b, "\t\tRelations: []string{%s},\n", quoted(e.relations))
	}
	fmt.Fprintf(&b, "\t\tAddr: func(x *%s, i int) any {\n\t\t\tswitch i {\n", E)
	for i, c := range e.columns {
		fmt.Fprintf(&b, "\t\t\tcase %d:\n\t\t\t\treturn &x.%s\n", i, c.field)
	}
	b.WriteString("\t\t\t}\n\t\t\treturn nil\n\t\t},\n\t}\n}\n")

	// The header and imports go last: rendering the body chose the imports.
	var out bytes.Buffer
	fmt.Fprintf(&out, "%s\n\npackage %s\n\n", header, e.pkg.Types.Name())
	im.write(&out)
	out.WriteString("\n")
	out.Write(b.Bytes())
	return format.Source(out.Bytes())
}
```

```go
// result is what a run would leave on disk.
type result struct {
	write  map[string][]byte // path → the content the file must have
	remove []string          // files velox-gen wrote that no entity produces now
}

// plan works out every file of a run without touching the disk.
func plan(ps []*packages.Package, cfg config) (result, []problem) {
	res := result{write: map[string][]byte{}}
	var probs []problem
	for _, p := range ps {
		ents, pr := discover(p, cfg)
		probs = append(probs, pr...)
		probs = append(probs, name(p, ents)...)
		for _, e := range ents {
			if _, err := os.Stat(e.out); err == nil && !isGenerated(e.out) {
				probs = append(probs, problem{e.pos, fmt.Sprintf("%s: %s exists and velox-gen did not write it", e.name, e.out)})
				continue
			}
			src, err := render(e)
			if err != nil {
				probs = append(probs, problem{e.pos, fmt.Sprintf("%s: the generated file does not format: %v", e.name, err)})
				continue
			}
			res.write[e.out] = src
		}
		for _, f := range p.GoFiles {
			if _, ok := res.write[f]; !ok && isGenerated(f) {
				res.remove = append(res.remove, f)
			}
		}
	}
	sort.Strings(res.remove)
	return res, probs
}
```

```go
// stale lists the files a run would change: written with other content, or
// removed.
func stale(res result) []string {
	var out []string
	for path, want := range res.write {
		if got, err := os.ReadFile(path); err != nil || !bytes.Equal(got, want) {
			out = append(out, path)
		}
	}
	out = append(out, res.remove...)
	sort.Strings(out)
	return out
}

// apply writes and removes the files of a run and returns the paths it
// changed. A file whose content is already right is left alone.
func apply(res result) ([]string, error) {
	changed := stale(res)
	for _, path := range changed {
		want, ok := res.write[path]
		if !ok {
			if err := os.Remove(path); err != nil {
				return nil, err
			}
			continue
		}
		if err := os.WriteFile(path, want, 0o644); err != nil {
			return nil, err
		}
	}
	return changed, nil
}
```

```go
// Command velox-gen writes the typed column handles and the scan plan of every
// velox entity: one file, <entity>_velox.go, beside each struct that declares
// func (x *T) Schema(s *velox.Schema).
//
// Install it as a tool of your module and run it from the module root:
//
//	go get -tool github.com/syssam/velox2/cmd/velox-gen
//	go tool velox-gen ./...
//
// Usage:
//
//	velox-gen [-check] [-ordered=path.Type,...] [-number=path.Type,...] [packages]
//	velox-gen verify [packages]
//
// velox-gen writes nothing when any entity has a problem. -check writes
// nothing and exits 1 when a generated file is out of date; CI runs it.
// verify builds every entity's metadata and reports mistakes in Schema and
// Mixin methods, which velox-gen itself cannot see because it never runs your
// code.
package main

import (
	"flag"
	"fmt"
	"io"
	"os"
	"path/filepath"
	"strings"
)

func main() {
	os.Exit(run(os.Args[1:], ".", nil, os.Stdout, os.Stderr))
}

// run is the command, with its directory, environment and output passed in
// so that tests can run it.
func run(args []string, dir string, env []string, stdout, stderr io.Writer) int {
	verify := len(args) > 0 && args[0] == "verify"
	if verify {
		args = args[1:]
	}
	fs := flag.NewFlagSet("velox-gen", flag.ContinueOnError)
	fs.SetOutput(stderr)
	checkOnly := fs.Bool("check", false, "write nothing; exit 1 when a generated file is out of date")
	ordered := fs.String("ordered", "", "comma-separated types, as import/path.Name, whose handles are ordered")
	number := fs.String("number", "", "comma-separated types, as import/path.Name, whose handles are numbers")
	if err := fs.Parse(args); err != nil {
		return 2
	}
	patterns := fs.Args()
	if len(patterns) == 0 {
		patterns = []string{"."}
	}
	cfg := config{dir: dir, env: env, ordered: typeSet(*ordered), number: typeSet(*number)}
	ps, err := load(cfg, patterns)
	if err != nil {
		fmt.Fprintf(stderr, "velox-gen: %v\n", err)
		return 1
	}
	if verify {
		return runVerify(cfg, ps, stdout, stderr)
	}
	res, probs := plan(ps, cfg)
	if report(stderr, probs) {
		return 1
	}
	if *checkOnly {
		files := stale(res)
		for _, f := range files {
			fmt.Fprintf(stderr, "velox-gen: %s is out of date\n", relPath(dir, f))
		}
		if len(files) > 0 {
			fmt.Fprintf(stderr, "velox-gen: run go tool velox-gen %s\n", strings.Join(patterns, " "))
			return 1
		}
		return 0
	}
	changed, err := apply(res)
	if err != nil {
		fmt.Fprintf(stderr, "velox-gen: %v\n", err)
		return 1
	}
	for _, f := range changed {
		fmt.Fprintln(stdout, relPath(dir, f))
	}
	return 0
}

// report prints problems and says whether there were any.
func report(w io.Writer, probs []problem) bool {
	for _, p := range probs {
		fmt.Fprintf(w, "velox-gen: %s\n", p)
	}
	return len(probs) > 0
}

func typeSet(s string) map[string]bool {
	m := map[string]bool{}
	for _, t := range strings.Split(s, ",") {
		if t = strings.TrimSpace(t); t != "" {
			m[t] = true
		}
	}
	return m
}

// relPath shows a path relative to dir when it is inside dir.
func relPath(dir, path string) string {
	abs, err := filepath.Abs(dir)
	if err != nil {
		return path
	}
	if r, err := filepath.EvalSymlinks(abs); err == nil {
		abs = r
	}
	if r, err := filepath.Rel(abs, path); err == nil && !strings.HasPrefix(r, "..") {
		return r
	}
	return path
}
```

```go
package main

import (
	"bytes"
	"fmt"
	"go/token"
	"io"
	"os"
	"os/exec"
	"path/filepath"
	"sort"

	"golang.org/x/tools/go/packages"
)

// runVerify builds every entity's metadata in a temporary program, inside the
// module of the loaded packages, and prints what it reports: a mistake in a
// Schema or Mixin method, or generated code that is out of date. The program
// lives in a directory named .velox-verify-*, which ./... ignores, and is
// removed afterwards.
func runVerify(cfg config, ps []*packages.Package, stdout, stderr io.Writer) int {
	var ents []*entity
	var probs []problem
	for _, p := range ps {
		e, pr := discover(p, cfg)
		ents, probs = append(ents, e...), append(probs, pr...)
	}
	if report(stderr, probs) {
		return 1
	}
	var named []*entity
	for _, e := range ents {
		if !token.IsExported(e.name) || e.pkg.Name == "main" {
			fmt.Fprintf(stderr, "velox-gen verify: skipping %s.%s, which a program outside its package cannot name\n", e.pkg.Name, e.name)
			continue
		}
		named = append(named, e)
	}
	if len(named) == 0 {
		fmt.Fprintln(stdout, "velox-gen verify: no entities")
		return 0
	}
	mod := named[0].pkg.Module
	for _, e := range named {
		if mod == nil || e.pkg.Module == nil || e.pkg.Module.Dir != mod.Dir {
			fmt.Fprintln(stderr, "velox-gen verify: the entities must be in one module; run verify once per module")
			return 1
		}
	}
	tmp, err := os.MkdirTemp(mod.Dir, ".velox-verify-")
	if err != nil {
		fmt.Fprintf(stderr, "velox-gen verify: %v\n", err)
		return 1
	}
	defer func() { _ = os.RemoveAll(tmp) }()
	if err := os.WriteFile(filepath.Join(tmp, "main.go"), verifyProgram(named), 0o644); err != nil {
		fmt.Fprintf(stderr, "velox-gen verify: %v\n", err)
		return 1
	}
	cmd := exec.Command("go", "run", "./"+filepath.Base(tmp))
	cmd.Dir, cmd.Env, cmd.Stdout, cmd.Stderr = mod.Dir, cfg.env, stdout, stderr
	if err := cmd.Run(); err != nil {
		return 1
	}
	return 0
}

// verifyProgram is a main package that calls velox.CheckEntity for every
// entity and exits 1 when any reports an error.
func verifyProgram(ents []*entity) []byte {
	sort.Slice(ents, func(i, j int) bool {
		if ents[i].pkg.PkgPath != ents[j].pkg.PkgPath {
			return ents[i].pkg.PkgPath < ents[j].pkg.PkgPath
		}
		return ents[i].name < ents[j].name
	})
	alias := map[string]string{}
	var paths []string
	for _, e := range ents {
		if _, ok := alias[e.pkg.PkgPath]; !ok {
			alias[e.pkg.PkgPath] = fmt.Sprintf("p%d", len(paths))
			paths = append(paths, e.pkg.PkgPath)
		}
	}
	var b bytes.Buffer
	fmt.Fprintf(&b, "// Code generated by velox-gen verify, which deletes it after running.\n\npackage main\n\nimport (\n\t\"fmt\"\n\t\"os\"\n\n\tvelox %q\n", veloxPath)
	for _, p := range paths {
		fmt.Fprintf(&b, "\t%s %q\n", alias[p], p)
	}
	b.WriteString(")\n\nfunc main() {\n\tfailed := 0\n\tfor _, err := range []error{\n")
	for _, e := range ents {
		fmt.Fprintf(&b, "\t\tvelox.CheckEntity[%s.%s](),\n", alias[e.pkg.PkgPath], e.name)
	}
	fmt.Fprintf(&b, "\t} {\n\t\tif err != nil {\n\t\t\tfmt.Fprintln(os.Stderr, err)\n\t\t\tfailed++\n\t\t}\n\t}\n"+
		"\tfmt.Printf(\"velox-gen verify: %%d entities, %%d with errors\\n\", %d, failed)\n"+
		"\tif failed > 0 {\n\t\tos.Exit(1)\n\t}\n}\n", len(ents))
	return b.Bytes()
}
```
