# Core 5 — Scale Guards — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the guards spec §9 requires, so that velox stays cheap to compile, link and run as applications grow:
- **Compile-cost guards:**
  - every method of a generic velox type is a `Lazy` generic method, with two named exceptions;
  - the handles' method sets are pinned;
  - generated code runs nothing at program start;
  - one variable of each generic type compiles to a small object.
- **Stale field types:** a field whose type changed without regeneration no longer compiles.
- **Render cache:** it is bounded in bytes as well as in shapes.
- **Allocation budgets:** they cover 100-row queries and metadata.
- **Fuzzing:** the SQL builder is fuzzed.
- **Scale harness:** `bench/scale` generates an application of N entities and S services and checks build cost against recorded thresholds in CI.

**Architecture:**
- **Guards are ordinary tests.** Static guards parse the source with `go/ast`. Object-size guards build tiny packages in a temporary module that points at this repository with a `replace` directive.
- **velox-gen catches stale types.** It writes, per entity, a function that is never called, `func _(x *Invoice) { var _ *float64 = &x.Total; … }`, which fails to compile when a field's type no longer matches the generated code. It costs nothing at run time.
- **`bench/scale`** is a `main` package in the root module, standard library only. It drives `go` and velox-gen and measures them.

**Tech Stack:** Go 1.27 standard library (`go/ast`, `os/exec`, `syscall` rusage); velox-gen.

**Spec:** `docs/history/specs/2026-10-14-core-design.md`, §8 (performance budget), §9 (testing: compile-cost guards, scale harness, fuzzing), §2 (stale code), §12 (risks). Also read "Plan 5 (scale guards)" in `docs/history/plans/2026-10-14-core-1-followups.md`; this plan resolves it, including the type-change staleness decision.

**This is plan 5 of 5 for Core.** Plans 1–4 are merged on `main`.

## Global Constraints

- **No dependencies.** The root module gains none; `bench/scale` and the guards use the standard library and the existing velox-gen module.
- **Offline temporary modules.** A temporary module that builds against this repository uses `replace github.com/syssam/velox2 => <repo root>`, the repository's `go.sum`, and `GOFLAGS=-mod=mod GOPROXY=off` so that it never touches the network (the module cache already holds the dependencies).
- **The ordinary test run stays fast.** `go test ./...` must not take more than a few seconds longer than it does now: the guards that build packages skip under `-short`, and CI runs them without it.
- **Thresholds are measured, then doubled.** Every threshold is measured on this machine and recorded with a margin of 2×, with the measured value beside it in a comment, because CI machines vary. Never set one by guessing.
- **Generated code changes.** It gains only the type-check function. `GeneratedCodeIsVersion2` stays, because the library is unchanged by it. `velox-gen -check` and `verify` must pass.
- **Every error velox creates starts with `velox: `.**

## Review Focus

1. **The guards fail on the regressions they name.**
   - What could slip through: an ordinary method on a generic type, a method granted to the wrong handle kind, a package-level call in generated code, or one generic type whose object grows several times.
   - Required: each must fail its guard.
   - Each guard's test proves this with a fixture or by mutation (Tasks 1, 2).
2. **A changed field type that was not regenerated fails to compile and names the field**, rather than querying with stale value types. Pinned by `TestStaleFieldTypeDoesNotCompile` (Task 2).
3. **The cache bound is real.** Many distinct IN arities cannot grow the render cache past its byte bound, and statements past the bound still render correctly. Pinned by `TestCacheBoundedInBytes` (Task 3).
4. **The fuzzer checks the properties that matter**: the number of placeholders equals the number of arguments, no argument value ever appears in the SQL text, quoted identifiers stay balanced, and the cached path equals the uncached one (Task 4).
5. **`bench/scale` measures what it claims.**
   - Its cold build uses an empty build cache.
   - Its incremental builds change a real field and regenerate.
   - Its link-memory figure comes from the linker process.
   - Its `-check` exits non-zero when a threshold is exceeded.

   Pinned by `TestScaleHarnessSmall` (Task 5).

```go
func TestMethodGuardCatchesAnOrdinaryMethod(t *testing.T) {
	src := `package velox
type Col[E, V any] struct{ I int32 }
func (c Col[E, V]) column(*E) int32 { return c.I }
func (c Col[E, V]) Bad() {}
func (c Col[E, V]) Good[_ Lazy[V]]() {}
type Rel[E, T any] struct{}
func (r Rel[E, T]) column(*E) int32 { return 0 }
`
	fset := token.NewFileSet()
	f, err := parser.ParseFile(fset, "x.go", src, parser.SkipObjectResolution)
	if err != nil {
		t.Fatal(err)
	}
	got := strings.Join(checkMethods(fset, f), "\n")
	for _, want := range []string{"method Bad of a generic type", "method column of Rel"} {
		if !strings.Contains(got, want) {
			t.Errorf("missing %q in:\n%s", want, got)
		}
	}

		t.Errorf("flagged an allowed method:\n%s", got)
	}
```

`internal/tempmod/tempmod.go`:

```go
// Package tempmod writes temporary Go modules that build against this
// repository, offline, for velox's build-cost tests and bench/scale.
package tempmod

import (
	"bytes"
	"fmt"
	"os"
	"os/exec"
	"path/filepath"
)

// Write creates a module example.com/tmp in dir that requires velox2 from
// repo (by replace), with the given files (path → content), and resolves its
// requirements from the module cache only.
func Write(dir, repo string, files map[string]string) error {
	mod := fmt.Sprintf("module example.com/tmp\n\ngo 1.27.0\n\nrequire github.com/syssam/velox2 v0.0.0\n\nreplace github.com/syssam/velox2 => %s\n", repo)
	sum, err := os.ReadFile(filepath.Join(repo, "go.sum"))
	if err != nil {
		return err
	}
	files["go.mod"], files["go.sum"] = mod, string(sum)
	for name, content := range files {
		p := filepath.Join(dir, name)
		if err := os.MkdirAll(filepath.Dir(p), 0o755); err != nil {
			return err
		}
		if err := os.WriteFile(p, []byte(content), 0o644); err != nil {
			return err
		}
	}
	_, err = Go(dir, "mod", "tidy")
	return err
}

// Go runs the go command in dir, offline, and returns its combined output.
func Go(dir string, args ...string) (string, error) {
	cmd := exec.Command("go", args...)
	cmd.Dir = dir
	cmd.Env = append(os.Environ(), "GOFLAGS=-mod=mod", "GOPROXY=off", "GOWORK=off")
	var out bytes.Buffer
	cmd.Stdout, cmd.Stderr = &out, &out
	err := cmd.Run()
	if err != nil {
		err = fmt.Errorf("go %v: %w\n%s", args, err, out.String())
	}
	return out.String(), err
}
```

```go
	files := map[string]string{"base/base.go": "package base\n\ntype E struct{ ID int64 }\n\nvar X int64\n"}

		files[g.name+"/p.go"] = fmt.Sprintf("package p\n\nimport \"github.com/syssam/velox2\"\n\ntype E struct{ ID int64 }\n\nvar X %s\n", g.decl)
```

### Task 1b: Keep reflect.Type out of velox's reachable types

*Added during execution: Task 1's size probe found that every package reaching `reflect.Type` through a type's fields or method signatures compiles about 140 KB of shape wrappers and type descriptors for `iter.Seq[reflect.Type]` and similar types, which have no home package. Every entity package reaches it today through `Meta → *EntityInfo → ColumnInfo.Type` and through `*Schema`'s fields. The linker removes the duplicates, so binaries do not grow; objects, build-cache size and compile CPU do.*

**Files:**
- Modify: `meta.go` (`ColumnInfo.Type`), `schema.go` (`field.typ`, `Schema.typ`), `relation.go` (`relation.typ`, `relation.fkTyp`), every reader of these, `compilecost_test.go`, `docs/history/specs/2026-10-14-core-design.md` (§3)

**Interfaces:**
- **`ColumnInfo.Type` stays a field**, typed `any`: it holds the field's `reflect.Type`. Add `func (ColumnInfo) …`? No: a method that returns `reflect.Type` brings the cost back. Instead add the package-level `func GoType(c ColumnInfo) reflect.Type { t, _ := c.Type.(reflect.Type); return t }`, documented as how a hook reads the Go type.
- **Unexported `reflect.Type` fields become `any`.** These are `field.typ`, `Schema.typ`, `relation.typ` and `relation.fkTyp`. Read them through small unexported package-level helpers (`rtype(v any) reflect.Type`).
- **No other velox type reachable from generated code, an entity's methods, `Statement` or a `Query` may hold `reflect.Type` or `reflect.Value` in a field or a method signature.**

```go
import (

// TestGeneratedCodeRunsNothingAtStart enforces design §3 rule 4: a generated
// file has no init function and no package-level call; its values are
// literals and zero values.
func TestGeneratedCodeRunsNothingAtStart(t *testing.T) {
	files, _ := filepath.Glob(filepath.Join(root, "internal/testmodel/*_velox.go"))
	if len(files) == 0 {
		t.Fatal("no generated files")
	}
	for _, name := range files {
		f, err := parser.ParseFile(token.NewFileSet(), name, nil, 0)
		if err != nil {
			t.Fatal(err)
		}
		for _, d := range f.Decls {
			switch d := d.(type) {
			case *ast.FuncDecl:
				if d.Name.Name == "init" {
					t.Errorf("%s: an init function", name)
				}
			case *ast.GenDecl:
				for _, s := range d.Specs {
					vs, ok := s.(*ast.ValueSpec)
					if !ok {
						continue
					}
					for _, v := range vs.Values {
						ast.Inspect(v, func(n ast.Node) bool {
							if _, call := n.(*ast.CallExpr); call {
								t.Errorf("%s: a package-level value calls a function", name)
							}
							_, lit := n.(*ast.FuncLit)
							return !lit // a function's body runs when it is called, not at start
						})
					}
				}
			}
		}
	}
}

// without regenerating fails the build, naming the field.

		t.Fatal(err)
	}

		src, err := os.ReadFile(p)
		if err != nil {
			t.Fatal(err)
		}
		files["m/"+filepath.Base(p)] = string(src)

	changed := strings.Replace(files["m/item.go"], "Qty       int64", "Qty       float64", 1)
	if changed == files["m/item.go"] {
```

```go
package velox

import (
	"strings"
	"testing"

// unquote reverses Dialect.quote: it strips the outer quote characters and
// halves the doubled ones; ok is false when s is not one quoted identifier.
func unquote(d Dialect, s string) (string, bool) {
	q := byte('"')
	if d == MySQL {
		q = '`'
	}
	if len(s) < 2 || s[0] != q || s[len(s)-1] != q {
		return "", false
	}
	var b strings.Builder
	in := s[1 : len(s)-1]
	for i := 0; i < len(in); i++ {
		if in[i] == q {
			if i+1 >= len(in) || in[i+1] != q {
				return "", false // a lone quote would end the identifier
			}
			i++
		}
		b.WriteByte(in[i])
	}
	return b.String(), true
}

func FuzzQuote(f *testing.F) {
	for _, s := range []string{"id", `a"b`, "a`b", `""`, "``", "", "x y", `\`} {
		f.Add(s)
	}
	f.Fuzz(func(t *testing.T, ident string) {
		for _, d := range []Dialect{Postgres, MySQL, SQLite} {
			var b strings.Builder
			d.quote(&b, ident)
			got, ok := unquote(d, b.String())
			if !ok || got != ident {
				t.Fatalf("%v: %q quoted as %s does not read back (%q, %v)", d, ident, b.String(), got, ok)
			}
		}
	})
}

// fuzzStatement builds a statement on invInfo from fuzz input: each byte picks
// an operation, a column and whether the value is s.
func fuzzStatement(ops []byte, s string) *Statement {
	st := &Statement{Op: OpSelect, Entity: invInfo}
	n := len(invInfo.Columns)
	var preds []node
	for i, b := range ops {
		col := int32(int(b>>4) % n)
		var v any = s
		if b&1 == 1 {
			v = int64(i)
		}
		switch b % 7 {
		case 0:
			preds = append(preds, node{op: opEQ, col: col, v: v})
		case 1:
			preds = append(preds, node{op: opIn, col: col, v: []any{v, s}})
		case 2:
			preds = append(preds, node{op: opLike, col: col, v: s})
		case 3:
			preds = append(preds, node{op: opBetween, col: col, v: v, w: s})
		case 4:
			if len(preds) > 1 {
				preds = []node{{op: opOr, kids: preds}}
			}
		case 5:
			if len(preds) > 0 {
				preds[len(preds)-1] = node{op: opNot, kids: []node{preds[len(preds)-1]}}
			}
		case 6:
			st.OrderBy = append(st.OrderBy, OrderTerm{Column: int(col), Desc: b&2 == 2})
		}
	}
	for _, p := range preds {
		st.Where = append(st.Where, Predicate{p})
	}
	if len(ops) > 0 && ops[0]&8 == 8 {
		st.Op, st.OrderBy = OpUpdate, nil
		st.Set = []Assignment{{Column: 1, Op: AssignSet, Value: s}}
	}
	if len(ops) > 0 && ops[0]&64 == 64 {
		st.Limit = len(ops)
	}
	return st
}

// placeholders counts the placeholders outside quoted identifiers.
func placeholders(d Dialect, sql string) int {
	q := byte('"')
	if d == MySQL {
		q = '`'
	}
	n, quoted := 0, false
	for i := 0; i < len(sql); i++ {
		c := sql[i]
		switch {
		case c == q:
			quoted = !quoted
		case quoted:
		case d == Postgres && c == '$':
			n++
		case d != Postgres && c == '?':
			n++
		}
	}
	return n
}

// FuzzRender is Review Focus 4: whatever the input, the SQL has as many
// placeholders as arguments, never contains an argument's text, keeps its
// quoted identifiers balanced, and the cache renders it identically.
func FuzzRender(f *testing.F) {
	f.Add([]byte{0, 1, 2, 3, 4, 5, 6}, `x'; DROP TABLE invoices; --`)
	f.Add([]byte{8 | 64, 16, 33}, "a\"b`c?$1")
	f.Add([]byte{}, "")
	f.Fuzz(func(t *testing.T, ops []byte, s string) {
		if len(ops) > 64 {
			ops = ops[:64]
		}
		for _, d := range []Dialect{Postgres, MySQL, SQLite} {
			st := fuzzStatement(ops, s)
			sql, args := render(d, st)
			if got := placeholders(d, sql); got != len(args) {
				t.Fatalf("%v: %d placeholders for %d arguments: %s", d, got, len(args), sql)
			}
			q := `"`
			if d == MySQL {
				q = "`"
			}
			if strings.Count(sql, q)%2 != 0 {
				t.Fatalf("%v: unbalanced quotes: %s", d, sql)
			}
			if len(s) >= 6 && strings.Contains(sql, s) {
				t.Fatalf("%v: an argument's text is in the SQL: %s", d, sql)
			}
			var c renderCache
			c.render(d, st)
			cached, cargs := c.render(d, fuzzStatement(ops, s))
			if cached != sql || !argsEqual(cargs, args) {
				t.Fatalf("%v: the cache renders differently:\n%s\n%s", d, sql, cached)
			}
		}
	})
}
```

Notes:
- **Escaping in `Like`.** `opLike`'s argument is escaped by `escapeLike` in the handle, not in rendering. Rendering never inlines the value, so the "argument text" property holds.
- **`$` and `?` inside a value.** Values are placeholders, so `$` or `?` in `s` never reaches the SQL.
- **Short values.** The `len(s) >= 6` guard avoids false alarms on short strings that occur in SQL keywords, such as `"id"` or `"OR"`.
- **`argsEqual`.** It is the render tests' helper. If it compares differently than the test needs, write a small `slices.EqualFunc` here.

```go
// repo is the root of this repository: bench/scale's grandparent.
func repo() (string, error) {
	_, file, _, ok := runtime.Caller(0)
	if !ok {
		return "", fmt.Errorf("cannot locate the repository")
	}
	return filepath.Abs(filepath.Join(filepath.Dir(file), "..", ".."))
}

func run(c config) (report, error) {
	r := report{N: c.n, Services: c.services}
	if c.n < 10 || c.n%10 != 0 || c.services < 1 {
		return r, fmt.Errorf("-n must be a multiple of 10 and -s at least 1")
	}
	root, err := repo()
	if err != nil {
		return r, err
	}
	if c.dir == "" {
		if c.dir, err = os.MkdirTemp("", "velox-scale-"); err != nil {
			return r, err
		}
		defer os.RemoveAll(c.dir)
	}
	app, tools, cache, bin := filepath.Join(c.dir, "app"), filepath.Join(c.dir, "tools"), filepath.Join(c.dir, "cache"), filepath.Join(c.dir, "bin")
	for _, d := range []string{tools, cache, bin} {
		if err := os.MkdirAll(d, 0o755); err != nil {
			return r, err
		}
	}
	domains := c.n / 10
	if err := tempmod.Write(app, root, generate(domains, c.services)); err != nil {
		return r, err
	}
	gen := filepath.Join(tools, "velox-gen")
	if out, err := exec.Command("go", "-C", filepath.Join(root, "cmd", "velox-gen"), "build", "-o", gen, ".").CombinedOutput(); err != nil {
		return r, fmt.Errorf("building velox-gen: %v\n%s", err, out)
	}
	wrapper := filepath.Join(tools, "linkmem")
	if err := buildWrapper(wrapper); err != nil {
		return r, err
	}
	velox := func(pkgs ...string) error {
		cmd := exec.Command(gen, pkgs...)
		cmd.Dir = app
		if out, err := cmd.CombinedOutput(); err != nil {
			return fmt.Errorf("velox-gen %v: %v\n%s", pkgs, err, out)
		}
		return nil
	}
	if err := velox("./..."); err != nil {
		return r, err
	}
	memFile := filepath.Join(tools, "linkmem.txt")
	build := func() (float64, error) {
		start := time.Now()
		cmd := exec.Command("go", "build", "-toolexec", wrapper, "-o", bin+string(filepath.Separator), "./...")
		cmd.Dir = app
		cmd.Env = append(os.Environ(), "GOCACHE="+cache, "GOFLAGS=-mod=mod", "GOPROXY=off", "GOWORK=off", "VELOX_LINKMEM="+memFile)
		if out, err := cmd.CombinedOutput(); err != nil {
			return 0, fmt.Errorf("go build: %v\n%s", err, out)
		}
		return time.Since(start).Seconds(), nil
	}
	if r.ColdBuildS, err = build(); err != nil {
		return r, err
	}
	edit := func(domain int) (float64, error) {
		p := filepath.Join(app, fmt.Sprintf("d%d", domain), "e5.go")
		src, err := os.ReadFile(p)
		if err != nil {
			return 0, err
		}
		field := fmt.Sprintf("\tExtra%d int64\n}", time.Now().UnixNano())
		changed := strings.Replace(string(src), "\n}\n\nfunc (x *E5) Schema", "\n"+field+"\n\nfunc (x *E5) Schema", 1)
		if changed == string(src) {
			return 0, fmt.Errorf("cannot edit %s", p)
		}
		if err := os.WriteFile(p, []byte(changed), 0o644); err != nil {
			return 0, err
		}
		if err := velox(fmt.Sprintf("./d%d", domain)); err != nil {
			return 0, err
		}
		return build()
	}
	if r.LeafRebuildS, err = edit(domains - 1); err != nil {
		return r, err
	}
	if r.RootRebuildS, err = edit(0); err != nil {
		return r, err
	}
	if fi, err := os.Stat(filepath.Join(bin, "s0")); err == nil {
		r.ServiceBinaryMB = float64(fi.Size()) / (1 << 20)
	} else {
		return r, err
	}
	r.LinkPeakMB, err = peakMB(memFile)
	return r, err
}

// generate writes the application's packages (path → source).
func generate(domains, services int) map[string]string {
	files := map[string]string{}
	for d := range domains {
		pkg := fmt.Sprintf("d%d", d)
		for k := range 10 {
			var b strings.Builder
			fmt.Fprintf(&b, "package %s\n\nimport (\n\t\"time\"\n\n\t\"github.com/syssam/velox2\"\n", pkg)
			if k == 0 && d > 0 {
				fmt.Fprintf(&b, "\n\t\"example.com/tmp/d%d\"\n", (d-1)/2)
			}
			fmt.Fprintf(&b, ")\n\n// E%d is a generated entity.\ntype E%d struct {\n\tID        int64\n\tName      string\n\tAmount    float64\n\tCreatedAt time.Time\n\tNote      *string\n", k, k)
			switch {
			case k == 0 && d > 0:
				fmt.Fprintf(&b, "\tUpID      int64\n\tUp        velox.One[d%d.E0]\n", (d-1)/2)
			case k > 0:
				fmt.Fprintf(&b, "\tPrevID    int64\n\tPrev      velox.One[E%d]\n", k-1)
			}
			if k == 0 {
				b.WriteString("\tNext      velox.Many[E1]\n")
			}
			if k == 1 {
				b.WriteString("\tE0ID      int64\n")
			}
			fmt.Fprintf(&b, "}\n\nfunc (x *E%d) Schema(s *velox.Schema) {}\n", k)
			files[filepath.Join(pkg, fmt.Sprintf("e%d.go", k))] = b.String()
		}
	}
	for s := range services {
		var imp, use strings.Builder
		seen := map[int]bool{}
		for m := range 5 {
			d := (s*7 + m) % domains
			if !seen[d] {
				seen[d] = true
				fmt.Fprintf(&imp, "\t\"example.com/tmp/d%d\"\n", d)
			}
			fmt.Fprintf(&use, "\tsink(db.Query[d%d.E%d]().Where(d%d.E%ds.ID.EQ(1)).Limit(1).SQL())\n", d, m, d, m)
		}
		files[filepath.Join(fmt.Sprintf("s%d", s), "main.go")] = fmt.Sprintf(
			"package main\n\nimport (\n\t\"fmt\"\n\n\t\"github.com/syssam/velox2\"\n%s)\n\nfunc sink(s string, _ []any) { fmt.Println(len(s)) }\n\nfunc main() {\n\tdb := velox.Open(velox.Postgres, nil)\n%s}\n",
			imp.String(), use.String())
	}
	return files
}
```

```go
// buildWrapper builds the -toolexec program that runs each tool and, for the
// linker, appends its peak memory in bytes to $VELOX_LINKMEM.
func buildWrapper(path string) error {
	dir, err := os.MkdirTemp("", "velox-linkmem-")
	if err != nil {
		return err
	}
	defer os.RemoveAll(dir)
	src := `package main

import (
	"fmt"
	"os"
	"os/exec"
	"path/filepath"
	"runtime"
	"strings"
	"syscall"
)

func main() {
	cmd := exec.Command(os.Args[1], os.Args[2:]...)
	cmd.Stdin, cmd.Stdout, cmd.Stderr = os.Stdin, os.Stdout, os.Stderr
	err := cmd.Run()
	if cmd.ProcessState != nil && strings.TrimSuffix(filepath.Base(os.Args[1]), ".exe") == "link" {
		if ru, ok := cmd.ProcessState.SysUsage().(*syscall.Rusage); ok {
			peak := int64(ru.Maxrss)
			if runtime.GOOS == "linux" {
				peak *= 1024 // kilobytes on Linux, bytes on macOS
			}
			if f, ferr := os.OpenFile(os.Getenv("VELOX_LINKMEM"), os.O_APPEND|os.O_CREATE|os.O_WRONLY, 0o644); ferr == nil {
				fmt.Fprintln(f, peak)
				f.Close()
			}
		}
	}
	if err != nil {
		if ee, ok := err.(*exec.ExitError); ok {
			os.Exit(ee.ExitCode())
		}
		os.Exit(1)
	}
}
`
	if err := os.WriteFile(filepath.Join(dir, "main.go"), []byte(src), 0o644); err != nil {
		return err
	}
	if err := os.WriteFile(filepath.Join(dir, "go.mod"), []byte("module linkmem\n\ngo 1.27.0\n"), 0o644); err != nil {
		return err
	}
	cmd := exec.Command("go", "build", "-o", path, ".")
	cmd.Dir = dir
	if out, err := cmd.CombinedOutput(); err != nil {
		return fmt.Errorf("building the toolexec wrapper: %v\n%s", err, out)
	}
	return nil
}

func peakMB(file string) (float64, error) {
	b, err := os.ReadFile(file)
	if err != nil {
		return 0, fmt.Errorf("no linker measurements: %w", err)
	}
	var peak int64
	for _, line := range strings.Fields(string(b)) {
		if v, err := strconv.ParseInt(line, 10, 64); err == nil && v > peak {
			peak = v
		}
	}
	return float64(peak) / (1 << 20), nil
}

// check compares r with the thresholds recorded for n entities.
func check(r report, n int, path string) []string {
	b, err := os.ReadFile(path)
	if err != nil {
		return []string{err.Error()}
	}
	var all map[string]map[string]any // a key starting with _ is a comment
	if err := json.Unmarshal(b, &all); err != nil {
		return []string{err.Error()}
	}
	th, ok := all[strconv.Itoa(n)]
	if !ok {
		return []string{fmt.Sprintf("no thresholds for n=%d in %s", n, path)}
	}
	got := map[string]float64{
		"cold_build_s": r.ColdBuildS, "leaf_rebuild_s": r.LeafRebuildS, "root_rebuild_s": r.RootRebuildS,
		"service_binary_mb": r.ServiceBinaryMB, "link_peak_mb": r.LinkPeakMB,
	}
	var problems []string
	for k, raw := range th {
		if strings.HasPrefix(k, "_") {
			continue // a comment
		}
		max, ok := raw.(float64)
		if !ok {
			problems = append(problems, fmt.Sprintf("threshold %s is not a number", k))
			continue
		}
		v, ok := got[k]
		if !ok {
			problems = append(problems, "unknown measurement "+k)
			continue
		}
		if v > max {
			problems = append(problems, fmt.Sprintf("%s = %.2f, over %.2f", k, v, max))
		}
	}
	return problems
}
```
