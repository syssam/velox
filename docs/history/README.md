# History

The specs, plans and reviews that built velox, kept as they were written. They are a record,
not documentation: they use the names of their day (`github.com/syssam/velox2`, `example/`,
`internal/gen`, `internal/itest`, `dbtype`), and what they call old velox is now veloxe.

For how the code works today, read the package docs and [CONTRIBUTING.md](../../CONTRIBUTING.md).
For why it is that way, read [the decisions](../decisions/).
