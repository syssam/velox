# orm-basic

The schema of [`examples/basic`](../basic) — users, posts, comments, tags —
generated by `velox-gen` instead of `velox`. The two examples share
`schema/` word for word, so they can be read side by side: only the generated
code and the way an application calls it differ.

```bash
go run generate.go   # writes ./velox from ./schema
go test ./...        # walkthrough_test.go: one test per thing an application does
```

`./velox` is checked in so that the generated code can be read without running
anything.

## What is generated

```
velox/
  velox.go                       the library's handle and errors under this package's name
  user.go, post.go, ...          velox.User, velox.Post: where every operation starts
  user/user.go, ...              one entity: its table, enums, columns and edges
  user/columns.go, ...           the column types (EQ, In, Set, Asc ... per Go type)
  entity/                        the row types, queries and builders
  predicate/                     the condition, assignment and order types
  migrate/                       the tables
  schemainit/                    the schema's defaults, validators and hooks
```

An application imports one package for all of it, `example.com/orm-basic/velox`.
It is named like the library, and gives the library's `DB`, `Tx`, `Executor`,
`IsNotFound`, `Must` and the rest under that name, so `velox.Tx` reads the
same in a file that imports the generated package and in one that imports the
library; they are one type.

## How it reads

```go
conn, err := velox.Open("sqlite", dsn)      // *velox.DB: the connection, no field per entity

// Create: the column is user.Name, the assignment user.Name.Set(v).
ann, err := velox.User.Create(conn).
    Set(user.Name.Set("ann"), user.Email.Set("ann@example.com"), user.Age.Set(30)).
    Save(ctx)

// Query: a condition is a method of the column.
adults, err := velox.User.Query(conn).
    Where(user.Age.GTE(18), user.Posts.HasWith(post.Status.EQ(post.StatusPublished))).
    OrderBy(user.Name.Asc()).
    With(user.Posts).
    All(ctx)

// Update and delete.
ann, err = velox.User.UpdateByID(conn, ann.ID).Set(user.Age.Add(1)).SaveOne(ctx)
err = velox.User.DeleteByID(conn, ann.ID).ExecOne(ctx)

// A transaction is given where the connection is.
err = conn.RunTx(ctx, func(tx *velox.Tx) error {
    _, err := velox.User.Create(tx).Set(user.Name.Set("bob"), user.Email.Set("bob@example.com")).Save(ctx)
    return err
})

// Errors are package velox's.
if velox.IsNotFound(err) { ... }
if errors.Is(err, velox.ErrUnique) { ... }
```

## Against `examples/basic`

| | `examples/basic` (`velox`) | here (`velox-gen`) |
|---|---|---|
| Start | `client.User.Query()` | `velox.User.Query(conn)` |
| In a transaction | `tx.User.Query()` | `velox.User.Query(tx)` |
| Set a field | `.SetName("ann")` | `.Set(user.Name.Set("ann"))` |
| Condition | `user.NameField.EQ("ann")` | `user.Name.EQ("ann")` |
| Edge condition | `user.HasPostsWith(...)` | `user.Posts.HasWith(...)` |
| Not found | `velox.IsNotFound(err)` | `velox.IsNotFound(err)` |
| Connection type | generated `*velox.Client`, a field per entity | `*velox.DB`, the library's |

The handle is an argument because no generated type lists every entity: a
package that uses three entities compiles three, whatever the size of the
schema. See [`docs/orm.md`](../../docs/orm.md).
